## Overview

The flexbox grid — `.row`, `.col-*`, `.offset-*`, `.row-cols-*`, and the `.g-*` gutter classes — is deprecated as of v0.6.0 and removed in v0.7.0. Its classes still compile and behave as before; the build prints one deprecation notice per compile. New layouts use the [Grid system]([[docsref:/layout/grid]]), and existing ones move to it class by class with the [migration table]([[docsref:/layout/grid#migrating]]).

<Example class="cxd-example-row" code={`<div class="container text-center">
    <div class="row">
      <div class="col">Column</div>
      <div class="col">Column</div>
      <div class="col">Column</div>
    </div>
  </div>`} />

## Rows and columns

`.row` is a wrapping flex container with negative inline margins of half the gutter; each direct child gets half the gutter as `padding-inline`. A `.row` needs a `.container`, or another padded parent, to absorb its negative margins.

`.col-{n}` sizes a column to `n` twelfths of the row, `.col` shares the remaining width equally, and `.col-auto` sizes a column to its content. A column with no class is full width.

<Example class="cxd-example-row" code={`<div class="container text-center">
    <div class="row">
      <div class="col-8">.col-8</div>
      <div class="col-4">.col-4</div>
    </div>
    <div class="row">
      <div class="col">.col</div>
      <div class="col-6">.col-6</div>
      <div class="col-auto">.col-auto</div>
    </div>
  </div>`} />

## Responsive classes

Every class has breakpoint variants. `.sm:col-*` alone stacks the columns below `sm`, and classes of several breakpoints set the width at each of them.

<Example class="cxd-example-row" code={`<div class="container text-center">
    <div class="row">
      <div class="sm:col-8">.sm:col-8</div>
      <div class="sm:col-4">.sm:col-4</div>
    </div>
    <div class="row">
      <div class="col-6 md:col-4">.col-6 .md:col-4</div>
      <div class="col-6 md:col-4">.col-6 .md:col-4</div>
      <div class="col-6 md:col-4">.col-6 .md:col-4</div>
    </div>
  </div>`} />

## Row columns

`.row-cols-{n}` on a `.row` gives every child an equal fraction of the row, from `1` to `6`; `.row-cols-auto` gives each child its content width.

<Example class="cxd-example-row" code={`<div class="container text-center">
    <div class="row row-cols-2 md:row-cols-4">
      <div class="col">Column</div>
      <div class="col">Column</div>
      <div class="col">Column</div>
      <div class="col">Column</div>
    </div>
  </div>`} />

## Offsets

`.offset-{n}` pushes a column `n` twelfths from the column before it with `margin-inline-start`. `.{breakpoint}:offset-0` resets an offset at a wider breakpoint.

<Example class="cxd-example-row" code={`<div class="container text-center">
    <div class="row">
      <div class="md:col-4">.md:col-4</div>
      <div class="md:col-4 md:offset-4">.md:col-4 .md:offset-4</div>
    </div>
    <div class="row">
      <div class="md:col-6 md:offset-3">.md:col-6 .md:offset-3</div>
    </div>
  </div>`} />

## Gutters

`.row` sets `--cx-gutter-x` to <code>{sassVars('grid').gutter}</code> (`$grid-gutter-x`) and `--cx-gutter-y` to `0` (`$grid-gutter-y`) at every breakpoint; the flexbox grid does not read the gutter tokens. `.gx-{size}` and `.gy-{size}` override one axis and `.g-{size}` both, with the sizes of the spacing scale and breakpoint variants. `.g-0` removes the gutters.

A vertical gutter is a top margin on the columns, cancelled by a negative top margin on the row; a horizontal gutter wider than the padding of the container overflows it. `.overflow-hidden` on the container clips both.

<Example class="cxd-example-row" code={`<div class="container overflow-hidden text-center">
    <div class="row g-xs">
      <div class="col-6">.col-6</div>
      <div class="col-6">.col-6</div>
      <div class="col-6">.col-6</div>
      <div class="col-6">.col-6</div>
    </div>
  </div>`} />

## Nesting

A `.row` inside a column is a grid of twelve columns across the width of that column.

<Example class="cxd-example-row" code={`<div class="container text-center">
    <div class="row">
      <div class="sm:col-3">Level 1: .sm:col-3</div>
      <div class="sm:col-9">
        <div class="row">
          <div class="col-8 sm:col-6">Level 2: .col-8 .sm:col-6</div>
          <div class="col-4 sm:col-6">Level 2: .col-4 .sm:col-6</div>
        </div>
      </div>
    </div>
  </div>`} />

## Dropping the classes

The flexbox grid is emitted while `$enable-grid-classes` is `true`, the default until v0.7.0. Set it to `false` once no markup uses the classes: the compiled CSS loses about 10 KB before compression, and the deprecation notice stops. `$enable-deprecation-messages: false` silences the notice without removing the classes.

```scss
@use "@chassis-ui/css/scss/config/settings" with (
  $enable-grid-classes: false
);
@use "@chassis-ui/css/scss/chassis";
```

## CSS

The variables and mixins below are deprecated with the classes. A mixin called from project code prints a deprecation warning when it compiles.

### Sass variables

`$grid-gutter-x`, `$grid-gutter-y`, and `$grid-row-columns` configure the flexbox grid only. `$gutters`, the map behind the `.g-*` classes, defaults to `$spaces`.

<ScssDocs name="grid-variables" file="scss/config/_defaults.scss" />

### Sass mixins

Each mixin has a replacement in the CSS Grid system: `make-row()` becomes a grid, `make-col()` a `grid-column` span, `make-col-offset()` a `grid-column-start`, and `row-cols()` a `grid-template-columns`. See [Semantic layouts]([[docsref:/layout/grid#semantic-layouts]]).
