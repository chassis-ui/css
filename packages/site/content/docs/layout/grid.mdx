import { sassVars, sassBreakpointSize, sassContainerSize } from '@libs/sass'

## Overview

The Chassis grid system arranges content with CSS Grid. `.grid` creates a twelve-column grid whose gap is the gutter token of the current breakpoint; span and placement classes position its items, with a variant for each of the six breakpoints.

<Example class="cxd-example-grid" code={`<div class="container text-center">
    <div class="grid">
      <div class="col-span-4">.col-span-4</div>
      <div class="col-span-4">.col-span-4</div>
      <div class="col-span-4">.col-span-4</div>
    </div>
  </div>`} />

Three items of four tracks each fill the twelve columns. The parent `.container` centers the grid and adds the page margin.

<Callout type="info">
The flexbox grid (`.row`, `.col-*`) is deprecated as of v0.6.0 and removed in v0.7.0. See [Flexbox grid]([[docsref:/layout/flexbox-grid]]) for the classes that still work and [Migrating](#migrating) for their replacements.
</Callout>

## How it works

The grid has three parts — container, grid, and items — and reads its measures from custom properties on `:root`:

- **Containers center and pad content.** `.container` applies a `max-width` per breakpoint and a `padding-inline` of `--cx-container-padding`, the page margin. A grid does not need a container: `.grid` has no negative margins to cancel. See [Containers]([[docsref:/layout/containers]]).
- **`.grid` defines the tracks.** It sets `display: grid` with `--cx-grid-columns` equal tracks of `minmax(0, 1fr)`, so content never widens a track, and a `gap` of `--cx-grid-gutter`.
- **Items span tracks.** A direct child of `.grid` occupies one track until a class says otherwise: `.col-span-{n}` spans `n` tracks, `.col-start-{n}` places the item on a grid line. See [Columns]([[docsref:/layout/columns]]).
- **The gutter follows the breakpoint.** `:root` declares `--cx-grid-gutter` at every breakpoint from the gutter tokens, so one grid has a narrow gap on a phone and a wide one on a desktop with no class. `--cx-grid-gap` or a gap utility overrides it per grid. See [Gutters]([[docsref:/layout/gutters]]).
- **Breakpoints are min-width media queries.** A prefixed class like `.md:col-span-6` applies from the `md` breakpoint upward. See [Breakpoints]([[docsref:/layout/breakpoints]]).
- **Class names and declarations match Tailwind's.** `col-span-6`, `col-start-3`, `row-span-2`, and `grid-cols-4` declare what the Tailwind utilities of the same names declare, so markup moves between the regular build and the [Tailwind entry]([[docsref:/getting-started/tailwind#grid-classes]]) unchanged.

## Spanning

`.col-span-{n}` makes an item span `n` tracks, from `1` to `12`. `.col-span-full` spans from the first grid line to the last, whatever the column count.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-8">.col-span-8</div>
    <div class="col-span-4">.col-span-4</div>
    <div class="col-span-full">.col-span-full</div>
  </div>`} />

### Auto columns

An item with no span class takes one track, so twelve of them fill a row:

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
  </div>`} />

Spanning and one-track items share a grid:

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-6">.col-span-6</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
    <div>1</div>
  </div>`} />

### Wrapping

An item that does not fit in the tracks left on a row moves to the next row. The gap applies between rows as it does between columns.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-9">.col-span-9</div>
    <div class="col-span-4">.col-span-4: 9 + 4 is more than 12, so the item starts a new row</div>
    <div class="col-span-6">.col-span-6</div>
  </div>`} />

## Placement

`.col-start-{n}` places an item on a grid line, from `1` to `13`, the line after the last track. `.row-span-{n}` and `.row-start-{n}` do the same on the row axis, and `.order-*` changes the visual order.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-3 col-start-2">.col-span-3 .col-start-2</div>
    <div class="col-span-4 col-start-7">.col-span-4 .col-start-7</div>
  </div>`} />

[Columns]([[docsref:/layout/columns]]) covers placement, rows, ordering, and alignment in full.

## Responsive classes

Every span and placement class has a variant per breakpoint. An unprefixed class applies at every width; a prefixed class applies from its breakpoint upward, until a class of a wider breakpoint overrides it.

### All breakpoints

Unprefixed classes keep one layout from the narrowest viewport to the widest.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-8">.col-span-8</div>
    <div class="col-span-4">.col-span-4</div>
  </div>`} />

### Stacked to horizontal

`.col-span-full` with a prefixed span stacks the items below a breakpoint and sets them side by side from it. The unprefixed class is needed: an item with only `.sm:col-span-8` is one track wide below `sm`, not full width.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-full sm:col-span-8">.col-span-full .sm:col-span-8</div>
    <div class="col-span-full sm:col-span-4">.col-span-full .sm:col-span-4</div>
  </div>`} />

### Mix and match

Classes of several breakpoints on one item set its span at each of them.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-6 md:col-span-4">.col-span-6 .md:col-span-4</div>
    <div class="col-span-6 md:col-span-4">.col-span-6 .md:col-span-4</div>
    <div class="col-span-6 md:col-span-4">.col-span-6 .md:col-span-4</div>
  </div>`} />

### Column counts

`.grid-cols-{n}` on the grid sets the number of tracks, from `1` to `12`, so equal items need no class of their own. Breakpoint variants change the count per breakpoint. See [Grid utilities]([[docsref:/utilities/grid#column-counts]]).

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-1 sm:grid-cols-2 md:grid-cols-4 text-center">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

## Alignment

Grid items stretch to the height of their row. `.align-items-*` on the grid and `.align-self-*` on an item change that; `.place-items-*` aligns on both axes. See [Columns]([[docsref:/layout/columns#alignment]]).

<Example class="cxd-example-grid cxd-example-grid-tall" code={`<div class="grid align-items-center text-center">
    <div class="col-span-4">.col-span-4</div>
    <div class="col-span-4">.col-span-4</div>
    <div class="col-span-4">.col-span-4</div>
  </div>`} />

## Gaps

The gap of a grid is `--cx-grid-gutter` unless `--cx-grid-gap` or a [gap utility]([[docsref:/utilities/gap]]) sets another. `.gap-{size}`, `.row-gap-{size}`, and `.column-gap-{size}` take the sizes of the spacing scale. See [Gutters]([[docsref:/layout/gutters]]).

<Example class="cxd-example-grid" code={`<div class="grid gap-xs text-center">
    <div class="col-span-6">.col-span-6</div>
    <div class="col-span-6">.col-span-6</div>
    <div class="col-span-6">.col-span-6</div>
    <div class="col-span-6">.col-span-6</div>
  </div>`} />

## Auto-fill

`.grid-fill` lays its children out in equal columns, as many as fit, with the gap of `.grid`. With no minimum width, every child shares one row:

<Example class="cxd-example-grid" code={`<div class="grid-fill text-center">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

`--cx-grid-min` sets the minimum width of a column. Columns that no longer fit wrap to a new row, which makes a card grid responsive with no breakpoint class:

<Example class="cxd-example-grid" code={`<div class="grid-fill text-center" style="--cx-grid-min: 12rem;">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

## Nesting

A `.grid` inside a grid item is a grid of its own, with twelve tracks across the width of the item. Nested spans count against the nested grid.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-full sm:col-span-3">Level 1: .sm:col-span-3</div>
    <div class="col-span-full sm:col-span-9">
      <div class="grid">
        <div class="col-span-8 sm:col-span-6">Level 2: .col-span-8 .sm:col-span-6</div>
        <div class="col-span-4 sm:col-span-6">Level 2: .col-span-4 .sm:col-span-6</div>
      </div>
    </div>
  </div>`} />

`--cx-grid-columns` is inherited: set on an element, it is the column count of every `.grid` inside until another element sets it again. A nested grid also has the gutter of the viewport in a fraction of its width — see [Narrow grids]([[docsref:/layout/gutters#narrow-grids]]).

### Subgrid

`.grid-cols-subgrid` on a nested `.grid` replaces its tracks with the tracks its item spans in the parent grid, so nested items align to the outer columns.

<Example class="cxd-example-grid" code={`<div class="grid text-center">
    <div class="col-span-8 grid grid-cols-subgrid">
      <div class="col-span-4">Subgrid .col-span-4</div>
      <div class="col-span-4">Subgrid .col-span-4</div>
    </div>
    <div class="col-span-4">.col-span-4</div>
  </div>`} />

## Content-width columns

A grid sizes its tracks from the container, not from the content. For items as wide as their content beside items that take the rest of the row, use a flex row: `.d-flex` with a gap utility, and `.flex-fill` on the items that grow. `gap: var(--cx-grid-gutter)` gives a flex row the gutter of the grid. See [Flex utilities]([[docsref:/utilities/flex]]).

<Example class="cxd-example-flex" code={`<div class="d-flex gap-md text-center">
    <div class="flex-fill p-sm">.flex-fill</div>
    <div class="p-sm">Content width</div>
    <div class="flex-fill p-sm">.flex-fill</div>
  </div>`} />

## Customizing

Custom properties configure one grid, or every grid inside an element, at runtime:

<CxTable>
| Property | Default | Description |
| --- | --- | --- |
| `--cx-grid-columns` | `:root`, from `$grid-column-counts` | Number of tracks of `.grid` |
| `--cx-grid-rows` | `1` | Number of explicit rows of `.grid` |
| `--cx-grid-gap` | `--cx-grid-gutter` | Gap of `.grid` and `.grid-fill`; one value, or `row-gap column-gap` |
| `--cx-grid-min` | `0` | Minimum column width of `.grid-fill` |
| `--cx-grid-gutter` | `:root`, from `$grid-gutters` | Gutter of the current breakpoint |
| `--cx-container-padding` | `:root`, from `$container-paddings` | Page margin of `.container` at the current breakpoint |
</CxTable>

`--cx-grid-rows`, `--cx-grid-gap`, and `--cx-grid-min` are not declared anywhere by default; `.grid` falls back to the value in the table until an element sets them.

<Example class="cxd-example-grid" code={`<div class="grid text-center" style="--cx-grid-columns: 4; --cx-grid-gap: 2rem;">
    <div class="col-span-2">.col-span-2</div>
    <div class="col-span-2">.col-span-2</div>
  </div>`} />

The span and start classes are generated up to `$grid-columns`. A grid with more columns than that needs an inline `grid-column` for the spans without a class.

## Migrating

Each class of the deprecated [flexbox grid]([[docsref:/layout/flexbox-grid]]) has a replacement:

<CxTable>
| Flexbox grid | CSS Grid | Notes |
| --- | --- | --- |
| `.row` | `.grid` | No `.container` needed around it |
| `.col-{n}` | `.col-span-{n}` | |
| `.col-12`, or no class below a breakpoint | `.col-span-full` | An item with no class is one track wide, not full width |
| `.offset-{n}` | `.col-start-{n + 1}` | Exact for the first item of a row: an offset counts from the previous item, a start line from the edge of the grid |
| `.row-cols-{n}` | `.grid-cols-{n}` | |
| `.g-{size}` | `.gap-{size}` | Not needed for the default gutter |
| `.gx-{size}`, `.gy-{size}` | `.column-gap-{size}`, `.row-gap-{size}` | |
| `.col` | `.grid-fill` on the parent, or `.d-flex` with `.flex-fill` | |
| `.col-auto` | `.d-flex` on the parent | See [Content-width columns](#content-width-columns) |
| `.justify-content-*` on a `.row` | `.col-start-*` on the items | The tracks fill the grid, so there is no free space to distribute |
| `.align-items-*`, `.align-self-*`, `.order-*` | Unchanged | |
| `.col-{n}` outside a `.row` | `.w-{n}/12` | A width, as on skeletons. See [Sizing]([[docsref:/utilities/sizing#fractions]]) |
| `.col`, `.col-auto` outside a `.row` | `.flex-fill`, `.w-auto` | |
| `.g-col-{n}`, `.g-start-{n}` | `.col-span-{n}`, `.col-start-{n}` | The old names still work until v0.7.0 |
| `.grid-cols-fill` | `.col-span-full` | |
</CxTable>

The gap of `.grid` differs from the gutter of `.row`: it is the gutter token of the breakpoint, not 1.5rem at every width, and it applies between rows too. Set `$enable-grid-classes: false` to compile without the flexbox grid.

### Semantic layouts

A grid on a custom selector needs no mixin: three declarations that read the `:root` custom properties, and `grid-column` on the items inside the breakpoint mixins.

```scss
.example-container {
  @include make-container();
  max-width: 800px;
}

.example-layout {
  display: grid;
  grid-template-columns: repeat(var(--cx-grid-columns), minmax(0, 1fr));
  gap: var(--cx-grid-gutter);
}

.example-content-main,
.example-content-secondary {
  grid-column: 1 / -1;
}

.example-content-main {
  @include media-breakpoint-up(sm) {
    grid-column: span 6;
  }
  @include media-breakpoint-up(lg) {
    grid-column: span 8;
  }
}

.example-content-secondary {
  @include media-breakpoint-up(sm) {
    grid-column: span 6;
  }
  @include media-breakpoint-up(lg) {
    grid-column: span 4;
  }
}
```
