## Introduction

Table styles are opt-in: the `.table` class enables them, so the native `<table>` elements of third-party widgets such as calendars and date pickers keep their own look. Modifier classes add stripes, hover and active states, borders and context colors. The styles reach only the direct rows and cells of a `.table`, so a nested table without the class is not styled.

## Basic structure

Add `.table` to a `<table>` element. Cells take their padding, their colors and a bottom border from the table, and the cells of the `<thead>` take the colors of the head.

<TableExample class="table" simplified={false} />

### Striped rows

Add `.striped` to give every other row of the `<tbody>` the striped colors.

### Striped columns

Add `.striped-columns` to stripe every other column instead of the rows.

## Hoverable rows

Add `.hoverable` to give the rows of the `<tbody>` a hover state.

<TableExample class="table hoverable striped" />

Add `.active` to a `<tr>` or to a single cell to highlight it. An active row or cell also gets a cue on its inline-start edge.

## Table borders

Border modifiers add borders around every cell, or remove the borders of a table.

### Bordered tables

Add `.bordered` for borders on all sides of the table and of its cells.

<TableExample class="table bordered" />

A [border color utility]([[docsref:/utilities/borders#color]]) changes the color of the borders:

<TableExample class="table bordered border-primary" />

### Borderless tables

Add `.borderless` for a table without borders.

<TableExample class="table borderless" />

### Border radius

The corners of a table take their radius from a design token. Set `--cx-border-radius` on the table to override it.

<TableExample class="table bordered" style="--cx-border-radius: 0" />

Set `--cx-table-border-radius` on a wrapper to give the radius to every table inside it.

<Example
  code={`<div style="--cx-table-border-radius: 1rem">
    ${getTableHtml({ class: 'table bordered' })}
  </div>`}
    customMarkup={`<div style="--cx-table-border-radius: 1rem">
    <table class="table bordered">
      ...
    </table>
  </div>`}
/>

The radius is part of the build while `$enable-table-border-radius` is `true`, its default in `scss/config/_settings.scss`.

## Context variants

<CSSOnly />

A context class gives a table the colors of a context. Add `.context` and a context name such as `.primary`; the `.solid` and `.smooth` classes change how strongly the color shows.

### Context colors

Add `.context` and a context name (`.context.primary`, `.context.success`) to a table, a `<thead>`, a `<tbody>`, a row or a single cell.

<Example code={`<table class="table">
    <thead>
      <tr>
        <th scope="col">Class</th>
        <th scope="col">Heading</th>
        <th scope="col">Heading</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <th scope="row">Base</th>
        <td>Cell</td>
        <td>Cell</td>
      </tr>
      ${getData('context-colors').map((contextColor) => {
        return (`
          <tr class="context ${contextColor.name}">
            <th scope="row">${contextColor.title}</th>
            <td>Cell</td>
            <td>Cell</td>
          </tr>
        `)
      }).join('')}
    </tbody>
  </table>`}
  customMarkup={[
  `<!-- On tables -->`,
  ...getData('context-colors').map((contextColor) => `<table class="table context ${contextColor.name}">...</table>`),
  `
  <!-- On heads -->
  <thead class="context primary">
    ...
  </thead>`,
  `
  <!-- On bodies -->
  <tbody class="context primary">
    ...
  </tbody>`,
  `
  <!-- On rows -->
  <tr class="context primary">
    ...
  </tr>`,
  `
  <!-- On cells (\`td\` or \`th\`) -->
  <td class="context primary">
    ...
  </td>`
]} />

## Table sizing

Custom properties set the cell padding and the font sizes of a table, in place of the values of the design tokens.

### Basic sizing

Set `--cx-cell-padding-y` and `--cx-td-font-size` on the table itself:

<TableExample class="table" style="--cx-td-font-size: 1rem; --cx-cell-padding-y: 1rem" />

### Targeted elements

Set the same properties on a `<thead>` or a `<tbody>` to size one section, or set the `--cx-table-*` properties on a wrapper to size every table inside it:

<Example
  code={`<div style="--cx-table-cell-padding-y: 1rem; --cx-table-th-font-size: 1rem;">
    ${getTableHtml({ class: 'table', headStyle: '--cx-cell-padding-y: .25rem', bodyStyle: '--cx-td-font-size: 1rem' })}
  </div>`}
    customMarkup={`<div style="--cx-table-cell-padding-y: 1rem; --cx-table-th-font-size: 1rem;">
    <table class="table">
      <thead style="--cx-cell-padding-y: .25rem">
        ...
      </thead>
      <tbody style="--cx-td-font-size: 1rem">
        ...
      </tbody>
    </table>
  </div>`}
/>

## Vertical alignment

Cells of the `<thead>` align their content to the middle, and cells of the `<tbody>` inherit the alignment of the table, which is `top` by default.

The [vertical align]([[docsref:/utilities/vertical-align]]) utilities (`.align-top`, `.align-middle`, `.align-bottom`) change the alignment of a table, a row or a single cell:

<Example code={`<div class="table-responsive">

          <th scope="col">Column 2</th>
          <th scope="col">Column 3</th>
          <th scope="col">Column 4</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td>This cell inherits <code>vertical-align: middle;</code> from the table</td>
          <td>This cell inherits <code>vertical-align: middle;</code> from the table</td>
          <td>This cell inherits <code>vertical-align: middle;</code> from the table</td>
          <td>This here is some long text, intended to take up quite a bit of vertical space, to demonstrate how the vertical alignment works in the preceding cells.</td>
        </tr>
        <tr class="align-bottom">
          <td>This cell inherits <code>vertical-align: bottom;</code> from the table row</td>
          <td>This cell inherits <code>vertical-align: bottom;</code> from the table row</td>
          <td>This cell inherits <code>vertical-align: bottom;</code> from the table row</td>
          <td>This here is some long text, intended to take up quite a bit of vertical space, to demonstrate how the vertical alignment works in the preceding cells.</td>
        </tr>
        <tr>

          <td>This here is some long text, intended to take up quite a bit of vertical space, to demonstrate how the vertical alignment works in the preceding cells.</td>
        </tr>

    </table>
  </div>`}
  customMarkup={`<div class="table-responsive">
    <table class="table align-middle">
      <thead>
        <tr>
          ...
        </tr>
      </thead>
      <tbody>
        <tr>
          ...
        </tr>
        <tr class="align-bottom">
          ...
        </tr>
        <tr>
          <td>...</td>

## Responsive tables

A `.table-responsive` wrapper lets a table scroll horizontally when it is wider than its container. `.max-{breakpoint}:table-responsive` limits the scrolling to viewports below a breakpoint.

<Callout type="warning">
**Vertical clipping/truncation**  
A responsive table scrolls inside its wrapper, which is positioned, so everything the table holds stays in it, absolutely positioned content included: a `.visually-hidden` header never widens the page. A menu in the last rows therefore opens inside the scroll area and is clipped at its bottom edge. Give its toggle `data-cx-strategy="fixed"` or `data-cx-container="body"` so the menu opens above the table.
</Callout>

## Sticky positioning

Pin the header row or the first column of a table so key labels stay visible while the rest of the table scrolls. `.sticky-header` and `.sticky-column` both use `position: sticky` on the affected cells — the header requires a scrolling ancestor on the block axis, the column pairs with `.table-responsive` for horizontal scrolling. Sticky cells keep the current row's `--bg-color` (striped, hover, and active states included), so they stay opaque over content scrolling underneath.

### Sticky header

Add `.sticky-header` to keep the `<thead>` visible while rows scroll past it. The table needs a scrolling ancestor on the vertical axis — here a wrapper with a fixed `max-height` and `overflow-y: auto`.

<Example code={[`<div class="overflow-y-auto" style="max-height: 12.5rem;">
    <table class="table sticky-header">
      <thead>
        <tr>
          <th scope="col">#</th>
          <th scope="col">Heading</th>
          <th scope="col">Heading</th>
          <th scope="col">Heading</th>
        </tr>
      </thead>
      <tbody>`,
        ...Array.from({ length: 10 }).map((_, i) => `<tr>
          <th scope="row">${i + 1}</th>
          <td>Cell</td>
          <td>Cell</td>
          <td>Cell</td>
        </tr>`), 
      `</tbody>
    </table>
  </div>`]}
  customMarkup={`<div class="overflow-y-auto" style="max-height: 12.5rem;">
    <table class="table sticky-header">
      ...
    </table>
  </div>`} />

### Sticky columns

Add `.sticky-column` to pin the first cell of every row to the inline-start edge, keeping row labels visible while the remaining columns scroll horizontally. Pair it with `.table-responsive` so the table has a horizontal scrolling ancestor.

## Stacked tables

Add `.stacked` to turn the rows of a table into stacked blocks. Each row becomes a block and each `<td>` a line of its own, with a label above its value. The label is the `data-cell` attribute of the `<td>`, set in the font of the head; the `<thead>` itself is hidden visually and stays available to screen readers.

`.stacked` uses container queries, so the table needs a `.table-responsive` wrapper as its query container. `.max-md:stacked`, `.max-lg:stacked` and the other breakpoint variants stack the table below that container width, and `.stacked` alone always stacks. Resize the example below to see the table switch between the two layouts.

<ResizableExample code={`<div class="table-responsive">
    <table class="table max-md:stacked">
      <thead>
        <tr>
          <th scope="col">Name</th>
          <th scope="col">Type</th>
          <th scope="col">Default</th>
          <th scope="col">Description</th>
        </tr>
      </thead>
      <tbody>
        <tr>
          <td data-cell="Name">animation</td>
          <td data-cell="Type">boolean</td>
          <td data-cell="Default">true</td>
          <td data-cell="Description">Applies a CSS fade transition on show and hide.</td>
        </tr>
        <tr>
          <td data-cell="Name">autohide</td>
          <td data-cell="Type">boolean</td>
          <td data-cell="Default">true</td>
          <td data-cell="Description">Hides the toast automatically after delay milliseconds. The timer pauses while the pointer is over the toast or focus is within it.</td>
        </tr>
        <tr>
          <td data-cell="Name">delay</td>
          <td data-cell="Type">number</td>
          <td data-cell="Default">5000</td>
          <td data-cell="Description">Milliseconds to wait before hiding. Only applies when autohide is true.</td>
        </tr>
      </tbody>
    </table>
  </div>`} />

```html
<!-- Always stacked -->
<div class="table-responsive">
  <table class="table stacked">...</table>
</div>

<!-- Stacked below md container width -->
<div class="table-responsive">
  <table class="table max-md:stacked">...</table>
</div>
```
