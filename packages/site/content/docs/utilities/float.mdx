## Overview

Float utilities set the CSS [`float` property](https://developer.mozilla.org/en-US/docs/Web/CSS/float) to `inline-start`, `inline-end`, or `none`, so `.float-start` and `.float-end` follow the writing direction. Each class has a variant per breakpoint, on the breakpoint scale of the grid. A float has no effect on a flex item.

<Example code={`<div class="float-start">Float start on all viewport sizes</div><br>
<div class="float-end">Float end on all viewport sizes</div><br>
<div class="float-none">Don’t float on all viewport sizes</div>`} />

Use the [clearfix utility]([[docsref:/helpers/clearfix]]) on a parent element to clear floats.

## Responsive

A breakpoint prefix applies a float value at that breakpoint and above:

<Example code={`<div class="sm:float-end">Float end on viewports sized "<b>sm</b>" or wider</div><br>
<div class="md:float-end">Float end on viewports sized "<b>md</b>" or wider</div><br>
<div class="lg:float-end">Float end on viewports sized "<b>lg</b>" or wider</div><br>
<div class="xl:float-end">Float end on viewports sized "<b>xl</b>" or wider</div><br>
<div class="2xl:float-end">Float end on viewports sized "<b>2xl</b>" or wider</div><br>`} />

Each float value has a class at every breakpoint:

<ul>
{getData('breakpoints').map((breakpoint) => {
  return (
    <Fragment>
      <li><code>.{breakpoint.abbr}float-start</code></li>
      <li><code>.{breakpoint.abbr}float-end</code></li>
      <li><code>.{breakpoint.abbr}float-none</code></li>
    </Fragment>
  )
})}
</ul>
