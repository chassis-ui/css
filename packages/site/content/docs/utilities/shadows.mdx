## Overview

Shadow utilities add or remove a `box-shadow`. The `$enable-component-shadows` Sass variable turns the shadows of components on or off; the utility classes apply their shadow whatever its value.

<Example class="overflow-hidden" code={`<div class="shadow-none rounded p-md mb-xl">No shadow</div>
<div class="shadow-sm rounded p-md mb-xl">Small shadow</div>
<div class="shadow rounded p-md mb-xl">Medium shadow</div>
<div class="shadow-lg rounded p-md mb-xl">Large shadow</div>
<div class="shadow-inset rounded p-md mb-md">Inset shadow</div>
<div class="shadow-emboss rounded p-md">Emboss shadow</div>`} />


### Elevation scale

`.shadow-{level}` classes apply the elevation shadows of the design tokens, named by their level.

<div class="cxd-example">
  {
    getData('color-values').map((value, index) => {
      return <p class={`shadow-${value.name} p-md rounded`} style={`margin-bottom: calc(1rem + (.25rem * ${index}))`}>This is <code>$cx-shadow-elevation-default-{value.name}</code> shadow.</p>
    })
  }
</div>

## Color shadows

An elevation shadow carries one layer whose color is the `--cx-shadow-color` custom property, transparent by default. A shadow color class sets that property to tint the shadow.

### How it works

Each elevation class draws one of its layers in `var(--cx-shadow-color, transparent)`. A `.shadow-{context}` class sets `--cx-shadow-color` to the context color at a low alpha, with the CSS relative color syntax, and the layer becomes visible. One color class therefore tints every elevation level, and the stylesheet holds no class per pair of color and level.

```css
.shadow-50 {
  box-shadow: 0rem 0.5rem 2rem -0.5rem rgba(0, 0, 0, 0.1), 0rem 0.25rem 1rem -0.25rem var(--cx-shadow-color, transparent), 0rem 0.25rem 1rem -0.25rem rgba(0, 0, 0, 0.1);
}
.shadow-primary {
  --cx-shadow-color: oklch(from var(--cx-primary) l c h / 0.2);
}
```

<Callout type="warning">
  The tint is computed in CSS and is not a design token, so a change of a colored shadow in Figma does not reach it.
</Callout>

### Color tinting

Combine an elevation class with a `.shadow-{context}` class to tint the shadow.

<div class="cxd-example">
  {
    getData('color-values').map((value, index) => {
      return <p class={`shadow-primary shadow-${value.name} p-md rounded`} style={`margin-bottom: calc(1rem + (.25rem * ${index}))`}>This is <code>$cx-shadow-elevation-primary-{value.name}</code> shadow.</p>
    })
  }
</div>

<Code lang="html" code={getData('color-values').map((value) => `<p class="shadow-primary shadow-${value.name}">...</p>`).join('\n')} />

## Hover shadows

The `hover:` prefix applies an elevation or shadow color class on `:hover` only: `.hover:shadow-30`, `.hover:shadow-primary`.

<Example code={`<p class="shadow-30-hover p-md rounded">This is a hover shadow.</p>
<p class="shadow-primary-hover shadow-50 p-md rounded">This is a shadow with primary hover.</p>`} />
