## Border

Border utilities add or remove element borders using `border-{side}` class patterns.

### Additive

These classes add borders to elements by side.

<Example class="cxd-example-border-utils" code={`<span class="border"></span>
<span class="border-top"></span>
<span class="border-end"></span>
<span class="border-bottom"></span>
<span class="border-start"></span>`} />

### Subtractive

Borders can be removed per-side on an element that already has a border applied.

<Example class="cxd-example-border-utils" code={`<span class="border border-0"></span>
<span class="border border-top-0"></span>
<span class="border border-end-0"></span>
<span class="border border-bottom-0"></span>
<span class="border border-start-0"></span>`} />

## Color

Border color utilities map to the Chassis context color palette.

<Callout>
Border color utilities generated from `$context-colors` do not yet respond to color mode changes. The `.border-*-subtle` variants do. This will be resolved in a future version.
</Callout>

<Example class="cxd-example-border-utils" code={[
  ...getData('context-colors').map((contextColor) => `<span class="border ${contextColor.name}-border-main"></span>
<span class="border ${contextColor.name}-border-subtle"></span>`)
]} />

Border color utilities can also override the default border on existing components:

<Example code={`<div class="mb-lg">
    <label for="exampleFormControlInput1" class="form-label">Email address</label>
    <input type="email" class="form-input border-success" id="exampleFormControlInput1" placeholder="name@example.com">
  </div>

  <div class="font-h4 pb-xs mb-lg fg-danger border-bottom border-danger">
    Dangerous heading
  </div>

  <div class="p-xs bg-info bg-opacity-10 border border-info border-start-0 rounded-end">
    Changing border color and width
  </div>`} />

## Opacity

### How it works

Border color utilities use CSS relative color syntax, enabling alpha opacity control through the `--cx-border-opacity` variable. The variable defaults to `1`.

```css
.border-primary {
  border-color: oklch(from var(--cx-primary) l c h / var(--cx-border-opacity, 1)) !important;
}
.border-opacity-50 {
  --cx-border-opacity: var(--cx-opacity-50);
}
```

### Opacity override

<Example code={`<div class="border border-primary p-2xs mb-sm">This is default primary border</div>
<div class="border border-primary p-2xs" style="--cx-border-opacity: .5;">This is 50% opacity primary border</div>`} />

Or, choose from any of the `.border-opacity` utilities:

<Example code={getData('token-opacities').map((opacity) => `<p class="border border-primary border-opacity-${opacity.name} p-2xs">This is -opacity-${opacity.name}- primary border</p>`)} />

### Context border opacity

<Example code={`<div class="border border-primary p-2xs mb-sm">This is <code>base-color</code> primary border</div>
<div class="border border-primary border-opacity-main p-2xs mb-sm">This is <code>cx-border-main</code> opacity primary border</div>
<div class="border border-primary border-opacity-subtle p-2xs mb-sm">This is <code>cx-border-subtle</code> opacity primary border</div>`} />

## Width

Border width utilities set the `--cx-border-width` variable from the design token scale. The border classes and the components read it, so a width class changes the border of `.border`, a side class or a component, wherever its rule comes in the stylesheet. A width class alone draws no border.

<Example class="cxd-example-border-utils" code={`<span class="border border-sm"></span>
<span class="border border-md"></span>
<span class="border border-lg"></span>
<span class="border border-xl"></span>
<span class="border border-2xl"></span>`} />

<Example class="cxd-example-border-utils" code={`<span class="border-bottom border-lg"></span>
<span class="border-start border-xl"></span>`} />

## Style

Border style utilities set the `--cx-border-style` variable, which the border classes and the components read. They set no `border-style` declaration, so a side class keeps the other sides without a border.

<Example class="cxd-example-border-utils" code={`<span class="border border-style-dashed"></span>
<span class="border-bottom border-style-dashed"></span>
<span class="border border-lg border-style-dashed"></span>`} />

A component sets `--cx-border-style` on itself, so a style class on an ancestor does not reach the components inside it. A style class on the component itself changes its outline and the dividers between its parts, such as the line under a card header. A line that marks a state keeps its own style: the top of the active tab, the underline of the active link.

<Example code={`<div class="card border-style-dashed">
  <div class="card-header">Header</div>
  <div class="card-body">The outline and both dividers are dashed.</div>
  <div class="card-footer">Footer</div>
</div>`} />
