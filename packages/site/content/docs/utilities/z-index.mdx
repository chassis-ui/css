## Overview

`z-index` utilities set the CSS `z-index` property, from `.z-n1` (`-1`) to `.z-5`. `z-index` takes effect only on an element whose `position` is not `static`: set it with a [position utility]([[docsref:/utilities/position]]) or in custom styles.

<Callout>
These utilities are low-level: their values, `-1` through `5`, order overlapping elements within a layout. Overlay components such as modals and tooltips use higher `z-index` values, defined separately.
</Callout>

<Example class="cxd-example-zindex-levels fg-main position-relative z-n1" code={`<div class="z-3 position-absolute p-4xl rounded"><span>z-3</span></div>
<div class="z-2 position-absolute p-4xl rounded"><span>z-2</span></div>

<div class="z-0 position-absolute p-4xl rounded"><span>z-0</span></div>
<div class="z-n1 position-absolute p-4xl rounded"><span>z-n1</span></div>`} />

## Overlays

Chassis overlay components — menus, modals, drawers, popovers, toasts, and tooltips — each have their own `z-index` value. The [`z-index` layout page]([[docsref:/layout/z-index]]) documents them.

## Component approach

Some components use the low-level `z-index` values to order the elements of a repeating group, such as the buttons of a button group. The [`z-index` scales]([[docsref:/about/extend#z-index-scales]]) section of the extend page describes the approach.
