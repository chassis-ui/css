## Overview

Grid utilities set the number of columns and rows of a grid and the way its items are placed. They act on `.grid`, the container of the [grid system]([[docsref:/layout/grid]]), and on any element with `display: grid` (`.d-grid`). The classes that place a single item — `.col-span-*`, `.col-start-*`, `.row-span-*`, `.row-start-*` — belong to the grid system and are covered in [Columns]([[docsref:/layout/columns]]).

## Column counts

`.grid-cols-{n}` sets `grid-template-columns` to `n` equal tracks, from `1` to `12`. On a `.grid` it replaces the column count of `--cx-grid-columns`, so items of equal width need no span class.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 text-center">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-4 text-center">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

Span classes count against the tracks of the utility:

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-4 text-center">
    <div>Item</div>
    <div class="col-span-2">.col-span-2</div>
    <div>Item</div>
    <div class="col-span-full">.col-span-full</div>
  </div>`} />

Each track is `minmax(0, 1fr)`, the declaration of the Tailwind utility of the same name, so wide content does not widen a track:

```css
.grid-cols-3 {
  grid-template-columns: repeat(3, minmax(0, 1fr));
}
```

<Callout type="warning">
`.grid-cols-fill`, which made an item span the whole grid, was removed in v0.7.0. Use `.col-span-full`.
</Callout>

## Row counts

`.grid-rows-{n}` sets `grid-template-rows` to `n` equal rows, from `1` to `6`. A `.grid` declares no rows of its own, so without the class each row is as tall as its content. The class applies to one grid, not to the grids nested in it.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-rows-2 text-center">
    <div class="row-span-2">.row-span-2</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

Each row is `minmax(0, 1fr)`, the declaration of the Tailwind utility of the same name. Items past the last explicit row create rows as tall as their content.

```css
.grid-rows-2 {
  grid-template-rows: repeat(2, minmax(0, 1fr));
}
```

## Auto flow

`.grid-auto-flow-{value}` sets `grid-auto-flow`, the direction in which items without a start line fill the grid.

### Row

`.grid-auto-flow-row`, the browser default, fills each row in turn and adds rows as needed.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-auto-flow-row text-center">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
    <div>Item 4</div>
    <div>Item 5</div>
  </div>`} />

### Column

`.grid-auto-flow-column` fills each column in turn and adds columns as needed. `.grid-rows-{n}` sets the number of rows a column holds.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-rows-2 grid-auto-flow-column text-center">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
    <div>Item 4</div>
    <div>Item 5</div>
  </div>`} />

### Dense

`.grid-auto-flow-dense` lets a later item fill a hole that an earlier, wider item left behind. The visual order can then differ from the DOM order.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-auto-flow-dense text-center">
    <div class="col-span-2">Item 1 (spans 2)</div>
    <div class="col-span-2">Item 2 (spans 2)</div>
    <div>Item 3</div>
    <div>Item 4</div>
  </div>`} />

## Responsive

Every grid utility has a variant per breakpoint.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-2 md:grid-cols-4 text-center">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

### Column counts

<ul>
{getData('breakpoints').map((breakpoint) => {
  return (
    <li><code>.{breakpoint.abbr}grid-cols-1</code> to <code>.{breakpoint.abbr}grid-cols-12</code></li>
  )
})}
</ul>

### Row counts

<ul>
{getData('breakpoints').map((breakpoint) => {
  return (
    <li><code>.{breakpoint.abbr}grid-rows-1</code> to <code>.{breakpoint.abbr}grid-rows-6</code></li>
  )
})}
</ul>

### Auto flow

<ul>
{getData('breakpoints').map((breakpoint) => {
  return (
    <Fragment>
      <li><code>.{breakpoint.abbr}grid-auto-flow-row</code></li>
      <li><code>.{breakpoint.abbr}grid-auto-flow-column</code></li>
      <li><code>.{breakpoint.abbr}grid-auto-flow-dense</code></li>
    </Fragment>
  )
})}
</ul>

### Container variants

Every grid utility also has a variant per container width, under the `@` prefix: `.@md:grid-cols-3` applies when the nearest query container is at least as wide as the `md` breakpoint. See [Container queries]([[docsref:/layout/grid#container-queries]]).
