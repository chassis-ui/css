## Overview

Grid utilities set the number of columns and rows of a grid and the way its items are placed. They act on `.grid`, the container of the [grid system]([[docsref:/layout/grid]]), and on any element with `display: grid` (`.d-grid`). The classes that place a single item — `.col-span-*`, `.col-start-*`, `.col-end-*`, `.row-span-*`, `.row-start-*`, `.row-end-*` — belong to the grid system and are covered in [Columns]([[docsref:/layout/columns]]).

## Column counts

`.grid-cols-{n}` sets `grid-template-columns` to `n` equal tracks, from `1` to `12`. On a `.grid` it replaces the column count of `--cx-grid-columns`, so items of equal width need no span class.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 text-center">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-4 text-center">
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

Span classes count against the tracks of the utility:

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-4 text-center">
    <div>Item</div>
    <div class="col-span-2">.col-span-2</div>
    <div>Item</div>
    <div class="col-span-full">.col-span-full</div>
  </div>`} />

Each track is `minmax(0, 1fr)`, the declaration of the Tailwind utility of the same name, so wide content does not widen a track:

```css
.grid-cols-3 {
  grid-template-columns: repeat(3, minmax(0, 1fr));
}
```

`.grid-cols-none` removes the template, which leaves the columns to [auto flow](#auto-flow) and the [implicit tracks](#implicit-tracks), and `.grid-cols-subgrid` takes the tracks of the parent grid — see [Subgrid]([[docsref:/layout/grid#subgrid]]). Both have the variants of the counts, so a template can be dropped or adopted at a breakpoint (`.md:grid-cols-subgrid`).

<Callout type="warning">
`.grid-cols-fill`, which made an item span the whole grid, was removed in v0.7.0. Use `.col-span-full`.
</Callout>

## Row counts

`.grid-rows-{n}` sets `grid-template-rows` to `n` equal rows, from `1` to `6`. A `.grid` declares no rows of its own, so without the class each row is as tall as its content. The class applies to one grid, not to the grids nested in it. `.grid-rows-none` removes a template set at a narrower breakpoint, and `.grid-rows-subgrid` takes the rows of the parent grid, on a nested grid that spans several of them.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-rows-2 text-center">
    <div class="row-span-2">.row-span-2</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
    <div>Item</div>
  </div>`} />

Each row is `minmax(0, 1fr)`, the declaration of the Tailwind utility of the same name. Items past the last explicit row create rows as tall as their content.

```css
.grid-rows-2 {
  grid-template-rows: repeat(2, minmax(0, 1fr));
}
```

## Auto flow

`.grid-flow-{value}` sets `grid-auto-flow`, the direction in which items without a start line fill the grid. The values are Tailwind's: `row`, `col`, `dense`, `row-dense`, and `col-dense`.

<Callout type="warning">
Until v0.7.0 these classes were `.grid-auto-flow-row`, `.grid-auto-flow-column`, and `.grid-auto-flow-dense`. They are now `.grid-flow-row`, `.grid-flow-col`, and `.grid-flow-dense`.
</Callout>

### Row

`.grid-flow-row`, the browser default, fills each row in turn and adds rows as needed.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-flow-row text-center">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
    <div>Item 4</div>
    <div>Item 5</div>
  </div>`} />

### Column

`.grid-flow-col` fills each column in turn and adds columns as needed. `.grid-rows-{n}` sets the number of rows a column holds.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-rows-2 grid-flow-col text-center">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
    <div>Item 4</div>
    <div>Item 5</div>
  </div>`} />

### Dense

`.grid-flow-dense` lets a later item fill a hole that an earlier, wider item left behind. `.grid-flow-row-dense` and `.grid-flow-col-dense` name the direction with it.

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-3 grid-flow-dense text-center">
    <div class="col-span-2">Item 1 (spans 2)</div>
    <div class="col-span-2">Item 2 (spans 2)</div>
    <div>Item 3</div>
    <div>Item 4</div>
  </div>`} />

<Callout type="warning">
Dense packing moves items out of their DOM order on screen, while keyboards and screen readers keep that order. Use it where the order carries no meaning, such as a gallery.
</Callout>

## Implicit tracks

A grid creates tracks beyond its template when it has more items than cells: rows in a row flow, columns in a column flow. `.auto-rows-{value}` and `.auto-cols-{value}` set their size with `grid-auto-rows` and `grid-auto-columns`: `auto` (the default, the size of the content), `min` (`min-content`), `max` (`max-content`), and `fr` (`minmax(0, 1fr)`, equal tracks).

<Example class="cxd-example-grid cxd-example-grid-tall" code={`<div class="grid grid-cols-3 auto-rows-fr text-center">
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
    <div>Item 4</div>
    <div>Item 5</div>
  </div>`} />

<Example class="cxd-example-grid" code={`<div class="grid grid-cols-none grid-flow-col auto-cols-max text-center">
    <div class="px-xs">Item</div>
    <div class="px-xs">A longer item</div>
    <div class="px-xs">Item</div>
  </div>`} />

Every grid utility has a variant per breakpoint.

    <div>Item</div>
    <div>Item</div>
  </div>`} />

### Implicit tracks

The implicit track utilities have a variant per breakpoint too: `.md:auto-rows-fr`, `.lg:auto-cols-max`.

### Container variants

Every grid utility also has a variant per container width, under the `@` prefix: `.@md:grid-cols-3` applies when the nearest query container is at least as wide as the `md` breakpoint. See [Container queries]([[docsref:/layout/grid#container-queries]]).
