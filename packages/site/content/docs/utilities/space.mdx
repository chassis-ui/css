## Overview

Space utilities control the spacing between direct children of an element by applying `margin-inline-end` or `margin-block-end` to all children except the last. [Gap utilities]([[docsref:/utilities/gap]]) need a flex or grid container; space utilities work on any parent element.

<Example class="" code={`<div class="space-x-md p-md bg-evident">
    <div class="d-inline-block p-sm bg-main">Item 1</div>
    <div class="d-inline-block p-sm bg-main">Item 2</div>
    <div class="d-inline-block p-sm bg-main">Item 3</div>
  </div>`} />

The selectors of space utilities are wrapped in `:where()` for zero specificity, so a margin utility or custom CSS on a child overrides them.

## Notation

Space classes that apply at all [breakpoints]([[docsref:/layout/breakpoints]]) have no breakpoint prefix — they start from `min-width: 0` and are not media-query-bound. Breakpoint-prefixed classes apply at that breakpoint and above.

The classes are named using the format `{property}-{size}` for `xs` and `{breakpoint}:{property}-{size}` for `sm`, `md`, `lg`, `xl`, and `2xl`.

Where *property* is one of:

- `space-x` — for classes that set horizontal spacing via `margin-inline-end`
- `space-y` — for classes that set vertical spacing via `margin-block-end`

Where *size* is one of:

<ul>
  <li>`zero` or `0` — for classes that eliminate spacing by setting it to `0`</li>

</ul>

## Horizontal

`.space-x-{size}` utilities control the horizontal space between children by applying `margin-inline-end` to all children except the last.

<Example code={`
  <div class="space-x-md p-md bg-evident">
    <div class="d-inline-block p-sm bg-main">Item 1</div>
    <div class="d-inline-block p-sm bg-main">Item 2</div>
    <div class="d-inline-block p-sm bg-main">Item 3</div>
  </div>`} />

## Vertical

`.space-y-{size}` utilities control the vertical space between children by applying `margin-block-end` to all children except the last.

<Example code={`
  <div class="space-y-md p-md bg-evident">
    <div class="p-sm bg-main">Item 1</div>
    <div class="p-sm bg-main">Item 2</div>
    <div class="p-sm bg-main">Item 3</div>
  </div>`} />

## How it works

Space utilities apply `margin-inline-end` or `margin-block-end` to every direct child except the last via a `:not(:last-child)` child selector. The selector is wrapped in `:where()` for zero specificity, so a margin utility on a child overrides the space.

```css
:where(.space-x-md > :not(:last-child)) {
  margin-inline-end: var(--cx-space-md);
}
:where(.space-y-md > :not(:last-child)) {
  margin-block-end: var(--cx-space-md);
}
```
