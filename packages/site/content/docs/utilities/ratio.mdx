## Overview

Ratio utilities set the CSS `aspect-ratio` property of an element, so its height follows its width. They suit embedded content such as `<iframe>`, `<embed>`, `<video>`, and `<object>` elements, and work on any other element, such as a `<div>` or an `<img>`. The `$aspect-ratios` Sass map holds the available ratios.

<Callout>
An `<iframe>` needs no `frameborder="0"` attribute: [Reboot]([[docsref:/content/reboot]]) removes its border.
</Callout>

## Example

Add a `.ratio-{ratio}` class to the element itself, an `<iframe>` or a `<video>` for example. The class sets no width, so pair it with a [width utility]([[docsref:/utilities/sizing]]) such as `.w-100`.

<Example code={`<iframe class="w-100 ratio-16x9" src="https://www.youtube.com/embed/LO2RPDZkY88?rel=0" title="YouTube video" allowfullscreen></iframe>`} />

The classes cover `1x1`, `4x3`, `16x9`, and `21x9`, and `.ratio-auto` for the `auto` value.

<Example class="cxd-example-ratios" code={`<div class="ratio-auto">
    <div>Auto</div>
  </div>
  <div class="w-25 ratio-1x1">
    <div>1×1</div>
  </div>
  <div class="w-50 ratio-4x3">
    <div>4×3</div>
  </div>
  <div class="w-75 ratio-16x9">
    <div>16×9</div>
  </div>
  <div class="w-100 ratio-21x9">
    <div>21×9</div>
  </div>`} />

## Custom ratios

A `.ratio-*` class sets the `--cx-aspect-ratio` custom property, and every element with such a class reads its `aspect-ratio` from it. Override the property for a ratio outside the set: `--cx-aspect-ratio: 2` on a `.ratio-auto` element gives a 2x1 ratio.

<Example class="cxd-example-ratios" code={`<div class="w-25 ratio-auto" style="--cx-aspect-ratio: 2;">
    <div>2x1</div>
  </div>`} />

A media query that sets the custom property changes the ratio at a breakpoint. The example starts at 4x3 and switches to a custom 2x1 at the `md` breakpoint.

<Example class="cxd-example-ratios cxd-example-ratios-breakpoint" code={`<div class="w-25 ratio-4x3">
    <div>4x3, then 2x1</div>
  </div>`} />
