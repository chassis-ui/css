## Overview

The `.opacity-{value}` utilities set the CSS `opacity` property on an element. A value of `1` is fully opaque, `.5` is 50% visible, and `0` is fully transparent.

<div class="cxd-example d-flex flex-wrap">
  {
    getData('token-opacities').map((opacity) => {
      return <div class={`bg-opacity-${opacity.name} fg-${opacity.name === 'solid' || opacity.name > 50 ? 'alternate' : 'default' } bg-default fg-opacity-80 p-sm m-xs rounded`}>{opacity.name}</div>
    })
  }
</div>

## Per-property opacity

The background, foreground, and border color utilities each read their alpha channel from a custom property, so the opacity of one color changes without affecting the rest of the element.

### How it works

These utilities depend on CSS relative color syntax. The color utility derives its color from the context color and reads the alpha channel from a `--cx-{type}-opacity` custom property, which defaults to `1`. A paired opacity utility sets that property.

```css
.bg-primary {
  --cx-bg-color: oklch(from var(--cx-primary) l c h / var(--cx-bg-opacity, 1));
}
.bg-opacity-50 {
  --cx-bg-opacity: var(--cx-opacity-50);
}
```

### Opacity override

Set the opacity property inline or with a `.bg-opacity-*` utility.

<Example code={`<div class="bg-primary p-xs primary-contrast-color">
    Primary background
  </div>
  <div style="--cx-bg-opacity: .4;" class="bg-primary p-xs">
    Primary background with 40% opacity
  </div>`} />

## Context opacities

Each color type also has opacity levels named after their role in the design tokens, next to the numeric scale.

### Foreground

`.fg-opacity-{level}` utilities apply the named foreground opacities to `.fg-*` color classes.

<Example code={`<p class="fg-primary">Base color</p>
<p class="fg-primary fg-opacity-a11y"><code>fg-a11y</code> opacity</p>
<p class="fg-primary fg-opacity-subtle"><code>fg-subtle</code> opacity</p>
<p class="fg-primary fg-opacity-slight"><code>fg-slight</code> opacity</p>`} />

The [color utilities]([[docsref:/utilities/colors#opacity]]) page covers foreground opacity in full.

### Background

`.bg-opacity-{level}` utilities apply the named background opacities to `.bg-*` color classes.

<Example code={`<div class="bg-primary p-xs">Base background</div>
<div class="bg-primary bg-opacity-main p-xs"><code>dim-main</code> opacity</div>
<div class="bg-primary bg-opacity-subtle p-xs"><code>dim-subtle</code> opacity</div>
<div class="bg-primary bg-opacity-slight p-xs"><code>dim-slight</code> opacity</div>`} />

The [background utilities]([[docsref:/utilities/background#opacity]]) page covers background opacity in full.

### Border

`.border-opacity-{level}` utilities apply the named border opacities to `.border-*` color classes.

<Example code={`<p class="border border-primary p-xs">Base border</p>
<p class="border border-primary border-opacity-main p-xs"><code>border-main</code> opacity</p>
<p class="border border-primary border-opacity-subtle p-xs"><code>border-subtle</code> opacity</p>`} />

The [border utilities]([[docsref:/utilities/borders#opacity]]) page covers border opacity in full.
