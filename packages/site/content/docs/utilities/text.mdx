## Text alignment

Text alignment utilities set the CSS `text-align` property. Responsive variants apply at the specified breakpoint and above, and container variants under the `@` prefix (`.@md:text-center`) at the same width of the nearest [query container]([[docsref:/layout/grid#query-containers]]).

<Example code={`<p class="text-start">Start aligned text on all viewport sizes.</p>
<p class="text-center">Center aligned text on all viewport sizes.</p>
<p class="text-end">End aligned text on all viewport sizes.</p>

<p class="sm:text-end">End aligned text on viewports sized "<b>sm</b>" or wider.</p>
<p class="md:text-end">End aligned text on viewports sized "<b>md</b>" or wider.</p>
<p class="lg:text-end">End aligned text on viewports sized "<b>lg</b>" or wider.</p>
<p class="xl:text-end">End aligned text on viewports sized "<b>xl</b>" or wider.</p>
<p class="2xl:text-end">End aligned text on viewports sized "<b>2xl</b>" or wider.</p>`} />

<Callout>
There is no utility class for justified text: it produces uneven word spacing, which reduces readability.
</Callout>

## Text wrapping

`.text-wrap` sets `white-space: normal`, so text breaks across lines when it reaches the edge of its container.

<Example code={`<div class="badge primary text-wrap" style="width: 6rem;">
    This text should wrap.
  </div>`} />

`.text-nowrap` keeps text on a single line, whatever the width of the container.

<Example code={`<div class="text-nowrap bg-evident border" style="width: 8rem;">
    This text should overflow the parent.
  </div>`} />

## Word break

`.text-break` keeps a long unbroken string from overflowing its container by setting `word-wrap: break-word` and `word-break: break-word`.

<Example code={`<p class="text-break">mmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmmm</p>`} />

<Callout type="warning">
[Arabic words cannot be broken](https://rtlstyling.com/posts/rtl-styling#3.-line-break), so `.text-break` does not suit content in Arabic, the most widely used RTL language.
</Callout>

## Text transform

Text transform utilities set the CSS `text-transform` property.

<Example code={`<p class="text-lowercase">Lowercased Text</p>
<p class="text-uppercase">uppercased text</p>
<p class="text-capitalize">capitalized text</p>
<p class="text-uppercase" lang="tr">istanbul</p>
<p class="text-lowercase" lang="tr">İSTANBUL</p>
<p class="text-capitalize" lang="tr">istanbul</p>`} />

`.text-capitalize` does not account for locale, even when `lang` is specified on the element.

## Font size

`.text-lg` and `.text-sm` scale the font size up or down in `em`, relative to the font size the element inherits.

<Example code={`<p class="font-lg">Easily make text <span class="text-lg">larger</span> or <span class="text-sm">smaller</span> to suit your design needs.</p>
<p class="font-sm">Easily make text <span class="text-lg">larger</span> or <span class="text-sm">smaller</span> to suit your design needs.</p>`} />

## Font weight and style

`.text-{weight}` classes set `font-weight`, and `.text-italic` and `.text-normal` set `font-style`.

<Example code={`<p class="text-bold">Bold text.</p>
<p class="text-bolder">Bolder weight text (relative to the parent element).</p>
<p class="text-semibold">Semibold weight text.</p>
<p class="text-md">Medium weight text.</p>
<p class="text-regular">Normal weight text.</p>
<p class="text-light">Light weight text.</p>
<p class="text-lighter">Lighter weight text (relative to the parent element).</p>
<p class="text-italic">Italic text.</p>
<p class="text-normal">Text with normal font style</p>`} />

## Line height

`.text-lh-{size}` utilities set `line-height`: `.text-lh-1` to `1`, and `.text-lh-sm`, `.text-lh-md`, and `.text-lh-lg` to the small, medium, and large line heights.

<Example code={`<p class="text-lh-1">This is a long paragraph written to show how the line-height of an element is affected by the utilities. Classes are applied to the element itself or sometimes the parent element. These classes can be customized as needed with the utility API.</p>
<p class="text-lh-sm">This is a long paragraph written to show how the line-height of an element is affected by the utilities. Classes are applied to the element itself or sometimes the parent element. These classes can be customized as needed with the utility API.</p>
<p class="text-lh-md">This is a long paragraph written to show how the line-height of an element is affected by the utilities. Classes are applied to the element itself or sometimes the parent element. These classes can be customized as needed with the utility API.</p>
<p class="text-lh-lg">This is a long paragraph written to show how the line-height of an element is affected by the utilities. Classes are applied to the element itself or sometimes the parent element. These classes can be customized as needed with the utility API.</p>`} />

## Text decoration

Text decoration utilities set or remove the line of the decoration, the CSS `text-decoration-line` property. They leave the color and thickness classes below alone, whichever class comes later in the stylesheet.

<Example code={`<p class="text-underline">This text has a line underneath it.</p>
<p class="text-line-through">This text has a line going through it.</p>
<a class="text-decoration-none" href="#">This link has its text decoration removed</a>`} />

### Thickness

Add `.text-decoration-{n}` to set the `text-decoration-thickness` property.

<Example code={`<p class="text-underline text-decoration-1">Decoration thickness 1</p>
<p class="text-underline text-decoration-2">Decoration thickness 2</p>
<p class="text-underline text-decoration-3">Decoration thickness 3</p>
<p class="text-underline text-decoration-4">Decoration thickness 4</p>`} />

### Color

`.text-decoration-{context}` sets the decoration to a context color and leaves the text color as it is.

<Example code={getData('context-colors').map((contextColor) => `<p class="text-underline text-decoration-${contextColor.name}">${titleCase(contextColor.title)} underline</p>`)} />

### Opacity

`.text-decoration-opacity-{value}` adjusts the alpha channel of the decoration color. Apply it alongside `.text-decoration` or any `.text-decoration-{color}` class, which set the decoration color as an opacity-aware value.

<Example code={[...getData('token-opacities').map((opacity) => `<p class="text-underline text-decoration text-decoration-opacity-${opacity.name}">Text decoration opacity ${opacity.name}</p>`)]} />

### Underline offset

`.underline-offset-{n}` sets `text-underline-offset` in `em` units, so the offset scales with the font size of the element.

<Example code={`<p class="text-underline">Standard underline</p>
<p class="text-underline underline-offset-1">Offset 1 underline</p>
<p class="text-underline underline-offset-2">Offset 2 underline</p>
<p class="text-underline underline-offset-3">Offset 3 underline</p>`} />
