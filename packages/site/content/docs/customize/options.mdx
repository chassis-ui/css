## Overview

Chassis CSS turns features on and off with `$enable-*` Sass variables. Each one is a switch for a part of the compiled CSS, so the options decide:

- **Bundle size**: leave out the features your project does not use
- **Rendering cost**: drop shadows, gradients, and transitions
- **Accessibility**: keep or replace the framework's handling of reduced motion and reduced transparency
- **Visual style**: rounded corners, shadows, carets, validation icons

### How to customize settings

The options are `!default` variables of `scss/config/_settings.scss`. Configure them with `@use … with (…)` on the `config` module, before the module that loads the framework:

```scss
// custom.scss
@use "@chassis-ui/css/scss/config" with (
  $enable-dark-mode: false,        // No dark mode
  $enable-validation-icons: false  // No icons in validated form fields
);

// Then load Chassis CSS
@use "@chassis-ui/css/scss/chassis";
```

Then recompile your CSS. A variable assigned in your file without `with (…)` belongs to your file and changes nothing in the framework — see [Variable defaults]([[docsref:/customize/sass#variable-defaults]]).

## Color mode type

In addition to the `$enable-*` variables above, the `$color-mode-type` variable controls how dark mode is implemented in your project:

- **`media-query`** (default): Relies solely on the `prefers-color-scheme` media query, automatically respecting the user's operating system settings.
- **`data`**: Uses a data attribute (`data-cx-theme="dark"`) to control theme switching, allowing user preference toggles and manual control.

Choose `data` when you want to provide a theme toggle in your UI, or `media-query` when you want to exclusively follow the system preference.

## Performance considerations

The options change the size of the CSS and the work the browser does to render it.

### Reducing bundle size

For smaller CSS files, consider disabling:

- **Visual effects**: Disable `$enable-background-gradients` and `$enable-component-shadows` for a more minimal style
- **Form features**: Turn off `$enable-validation-icons` if you implement custom validation UI
- **Transitions**: Set `$enable-transitions: false` for a more minimal build

### Runtime performance

For better rendering performance, especially on lower-powered devices:

- **Fewer animations**: Set `$enable-transitions: false` to eliminate transition animations
- **Simpler rendering**: Disable `$enable-component-shadows` and `$enable-background-gradients` to reduce GPU/CPU load
- **Typography**: Consider `$enable-fluid-font-sizes: false` if you don't need responsive font scaling

### Production builds

When deploying to production:

- Set `$enable-deprecation-messages: false` to keep the build output free of deprecation warnings
- Consider `$enable-smooth-scroll: false` if you implement custom scroll behaviors
- Audit your usage of dark mode with `$enable-dark-mode` - disable if unused
