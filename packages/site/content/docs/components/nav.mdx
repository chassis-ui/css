## Introduction

The nav is a set of links for moving between pages, views, or sections of a page. Every nav shares the `.nav` base class and `.nav-link` items; modifier classes on the `.nav` element change the visual style and the size without changing the markup.

### Key features

- Flexbox base that wraps by default and accepts flex utilities for alignment and stacking
- Three variants on the same markup: `.nav-tabs`, `.nav-segments`, and `.nav-underline`
- Three sizes through the `.sm` and `.lg` modifiers
- Works on `<ul>`, `<ol>`, and `<nav>` elements, with `<a>` or `<button>` links
- Icons and menu toggles inside `.nav-link`, sized and spaced with the link
- Integrates with the Collapse, Menu, Tab, and Nav overflow JavaScript plugins

## Basic structure

A nav is a `.nav` container holding `.nav-item` elements, each wrapping a `.nav-link`. Add `.active` to the link for the current page and `.disabled` to a link that is unavailable. The base class resets the list styling, lays the items out in a wrapping row, and pads each link for a larger hit area.

<Example code={`<ul class="nav">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

<Callout>
Convey the active state to assistive technologies with the `aria-current` attribute — `page` for the current page, or `true` for the current item in a set.
</Callout>

### Alternative markup

The `.nav-item` wrapper is optional. Because `.nav` is a flex container, `.nav-link` elements placed directly inside a `<nav>` element lay out the same way as wrapped ones. Use an `<ol>` instead of a `<ul>` when the order of the items carries meaning.

<Example code={`<nav class="nav" aria-label="Example navigation">
    <a class="nav-link active" aria-current="page" href="#">Active</a>
    <a class="nav-link" href="#">Link</a>
    <a class="nav-link" href="#">Link</a>
    <a class="nav-link disabled" aria-disabled="true">Disabled</a>
  </nav>`} />

### Button links

Use a `<button>` element for a link that triggers an action instead of navigating, such as a menu toggle. Buttons and anchors share the same `.nav-link` styles and can sit in the same nav.

<Example code={`<nav class="nav" aria-label="Example navigation with menu">
    <a class="nav-link active" aria-current="page" href="#">Active</a>
    <a class="nav-link" href="#">Link</a>
    <button type="button" class="nav-link" data-cx-toggle="menu" aria-expanded="false">Menu</button>
    <div class="menu">
      <a class="menu-item" href="#">Action</a>
      <a class="menu-item" href="#">Another action</a>
      <hr class="menu-divider">
      <a class="menu-item" href="#">Something else here</a>
    </div>
    <a class="nav-link disabled" aria-disabled="true">Disabled</a>
  </nav>`} />

## Variants

The variant classes restyle the same markup. Add one to the `.nav` element; without a variant class, the nav shows plain links with a background on the hovered and the active link.

### Tabs

`.nav-tabs` draws a border under the nav and frames the active link as a tab that joins the content below it, with an accent border along its top edge.

<Example code={`<ul class="nav nav-tabs">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

### Segments

`.nav-segments` places the links inside a rounded bar and raises the active link on its own surface, in the manner of a segmented control. The bar is an inline flex container, so it is only as wide as its links.

<Example code={`<ul class="nav nav-segments">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

### Underline

`.nav-underline` draws a border under the nav and marks the active link with a thicker accent underline. The links have no horizontal padding; a gap separates them instead.

<Example code={`<ul class="nav nav-underline">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

## Size variants

The `.lg` and `.sm` modifiers on the `.nav` element change the link padding, the gap inside the link, the icon and caret size, and the font size. Without a modifier, the medium size applies. Both modifiers combine with every variant: `.nav-segments` also scales the padding and corner radius of its bar, and `.nav-underline` scales the gap between its links.

## Content components

A `.nav-link` holds more than a text label. Icons and menu toggles sit inside the link, align with the label, and scale with the nav size.

### Icons

Place an icon inside the `.nav-link`, before or after the label. The link is a flex container, so the icon is centered on the label and separated from it by the link gap. The icon takes its size from `--cx-nav-link-icon-size` and its color from the link, including the hover, active, and disabled states.

<Example code={`<ul class="nav">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">
        <Icon name="home-outline" />
        Home
      </a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">
        <Icon name="chart-line-up-outline" />
        Reports
      </a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">
        <Icon name="bell-outline" />
        Alerts
      </a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">
        <Icon name="gear-outline" />
        Settings
      </a>
    </li>
  </ul>`} />

### Menus

A `.nav-link` can toggle a menu. Place a `<button>` toggle with `data-cx-toggle="menu"` and its `.menu` inside the same `.nav-item`, and add `.caret` to the toggle to draw the indicator. The toggle keeps its hover style while the menu is open. Menus require the [Menu JavaScript plugin]([[docsref:/components/menu#javascript-api]]).

<Example code={`<ul class="nav nav-tabs">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <button type="button" class="nav-link caret" data-cx-toggle="menu" aria-expanded="false">Menu</button>
      <div class="menu">
        <a class="menu-item" href="#">Action</a>
        <a class="menu-item" href="#">Another action</a>

    </li>
  </ul>`} />

## Layout options

The nav is a flex container, so [flex utilities]([[docsref:/utilities/flex]]) control its alignment and direction. Two modifier classes control how the links share the available width.

### Alignment

Navs align to the start of the row by default. Add `.justify-content-center` to center the links.

<Example code={`<ul class="nav justify-content-center">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

Add `.justify-content-end` to align the links to the end of the row.

<Example code={`<ul class="nav justify-content-end">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

### Vertical

Add `.flex-column` to stack the links. Combine it with a responsive variant, as in `.flex-column` with `.sm:flex-row`, to stack the links only below a breakpoint.

<Example code={`<ul class="nav flex-column">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

The same utility applies to `<nav>`-based markup.

<Example code={`<nav class="nav flex-column" aria-label="Vertical navigation">
    <a class="nav-link active" aria-current="page" href="#">Active</a>
    <a class="nav-link" href="#">Link</a>
    <a class="nav-link" href="#">Link</a>
    <a class="nav-link disabled" aria-disabled="true">Disabled</a>
  </nav>`} />

### Fill and justify

`.nav-fill` and `.nav-justified` stretch the links across the full width of the nav. With `.nav-fill`, the links grow in proportion to their content, so a longer label gets a wider link. `.nav-segments` is an inline flex container, so the examples add `.d-flex` to let the bar span the full width.

<Example code={`<ul class="nav nav-segments d-flex nav-fill flex-column sm:flex-row">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Much longer nav link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

With `<nav>`-based markup, the `.nav-link` elements stretch directly and `.nav-item` is not needed.

<Example code={`<nav class="nav nav-segments d-flex nav-fill flex-column sm:flex-row" aria-label="Fill navigation">
    <a class="nav-link active" aria-current="page" href="#">Active</a>
    <a class="nav-link" href="#">Much longer nav link</a>
    <a class="nav-link" href="#">Link</a>
    <a class="nav-link disabled" aria-disabled="true">Disabled</a>
  </nav>`} />

`.nav-justified` gives every link the same width, regardless of the length of its label.

<Example code={`<ul class="nav nav-segments d-flex nav-justified flex-column md:flex-row">
    <li class="nav-item">
      <a class="nav-link active" aria-current="page" href="#">Active</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Much longer nav link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link" href="#">Link</a>
    </li>
    <li class="nav-item">
      <a class="nav-link disabled" aria-disabled="true">Disabled</a>
    </li>
  </ul>`} />

`.nav-justified` applies to `<nav>`-based markup in the same way.

<Example code={`<nav class="nav nav-segments d-flex nav-justified flex-column md:flex-row" aria-label="Justified navigation">
    <a class="nav-link active" aria-current="page" href="#">Active</a>
    <a class="nav-link" href="#">Much longer nav link</a>
    <a class="nav-link" href="#">Link</a>
    <a class="nav-link disabled" aria-disabled="true">Disabled</a>
  </nav>`} />

## Advanced features

Navs combine with the Collapse, Tab, and Nav overflow plugins for expandable sections, tabbed interfaces, and navigation that adapts to the available width.

### Collapsible sections

Add `.collapsible` to a `.nav-item` to turn its link into the toggle of a nested nav. The link pushes a caret to its end, and the caret flips when the section opens. Give the link `data-cx-toggle="collapse"` and point its `href` at the `.collapse` element that wraps the nested nav; the Collapse plugin keeps `aria-expanded` in sync.

<Example code={`<ul class="nav flex-column">
    <li class="nav-item collapsible border-bottom">
      <a class="nav-link" href="#navCollapse1" data-cx-toggle="collapse" aria-expanded="false" aria-controls="navCollapse1">Collapsed item</a>
      <div class="collapse" id="navCollapse1">
        <nav class="nav flex-column ps-md" aria-label="Collapsed item links">
          <a class="nav-link" href="#">Child item 1</a>
          <a class="nav-link" href="#">Child item 2</a>
          <a class="nav-link" href="#">Child item 3</a>
        </nav>
      </div>
    </li>
    <li class="nav-item collapsible">
      <a class="nav-link" href="#navCollapse2" data-cx-toggle="collapse" aria-expanded="true" aria-controls="navCollapse2">Expanded item</a>
      <div class="collapse show" id="navCollapse2">
        <nav class="nav flex-column ps-md" aria-label="Expanded item links">
          <a class="nav-link" href="#">Child item 1</a>
          <a class="nav-link" href="#">Child item 2</a>
          <a class="nav-link" href="#">Child item 3</a>
        </nav>
      </div>
    </li>
  </ul>`} />

To keep a single section open at a time, add the same `data-cx-parent` selector to every `.collapse` element. Opening a section then closes the others inside that parent. See [Collapse]([[docsref:/components/collapse]]) for the plugin options.

<Example code={`<ul class="nav flex-column" id="navAccordion">
    <li class="nav-item collapsible border-bottom">
      <a class="nav-link" href="#navCollapse3" data-cx-toggle="collapse" aria-expanded="true" aria-controls="navCollapse3">First section</a>
      <div class="collapse show" id="navCollapse3" data-cx-parent="#navAccordion">
        <nav class="nav flex-column ps-md" aria-label="First section links">
          <a class="nav-link" href="#">Child item 1</a>
          <a class="nav-link" href="#">Child item 2</a>
          <a class="nav-link" href="#">Child item 3</a>
        </nav>
      </div>
    </li>
    <li class="nav-item collapsible border-bottom">
      <a class="nav-link" href="#navCollapse4" data-cx-toggle="collapse" aria-expanded="false" aria-controls="navCollapse4">Second section</a>
      <div class="collapse" id="navCollapse4" data-cx-parent="#navAccordion">
        <nav class="nav flex-column ps-md" aria-label="Second section links">
          <a class="nav-link" href="#">Child item 1</a>
          <a class="nav-link" href="#">Child item 2</a>
          <a class="nav-link" href="#">Child item 3</a>
        </nav>
      </div>
    </li>
    <li class="nav-item collapsible">
      <a class="nav-link" href="#navCollapse5" data-cx-toggle="collapse" aria-expanded="false" aria-controls="navCollapse5">Third section</a>
      <div class="collapse" id="navCollapse5" data-cx-parent="#navAccordion">
        <nav class="nav flex-column ps-md" aria-label="Third section links">
          <a class="nav-link" href="#">Child item 1</a>
          <a class="nav-link" href="#">Child item 2</a>
          <a class="nav-link" href="#">Child item 3</a>
        </nav>
      </div>
    </li>
  </ul>`} />

### Tabbed interfaces

The Tab plugin turns a nav into a tabbed interface that shows one `.tab-pane` at a time and manages the ARIA roles and keyboard interaction. See [Tab]([[docsref:/components/tab]]) for the markup and the JavaScript API.

### Overflow

The Nav overflow plugin moves the links that do not fit the width of the nav into a "More" menu. See [Nav overflow]([[docsref:/components/nav-overflow]]) for the wrapper markup and options.

## Accessibility

A nav conveys its role, the current link, and unavailable links through semantic markup and ARIA attributes.

- Expose site or section navigation as a landmark: use a `<nav>` element, or add `role="navigation"` to the closest logical parent of the `<ul>`. Do not add the role to the `<ul>` itself, since that prevents assistive technologies from announcing it as a list.
- Give each landmark a distinct `aria-label` when a page holds more than one nav.
- Mark the current link with `aria-current="page"`, or `aria-current="true"` for the current item in a set.
- Add `aria-disabled="true"` to a disabled link and omit its `href`. `.disabled` removes pointer events, but an anchor with an `href` stays reachable from the keyboard.

Navigation styled as tabs with `.nav-tabs` must **not** carry `role="tablist"`, `role="tab"`, or `role="tabpanel"`. These roles belong to dynamic tabbed interfaces, as described in the [ARIA Authoring Practices Guide tabs pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/). In a tabbed interface built with the [Tab plugin]([[docsref:/components/tab]]), the plugin sets `aria-selected="true"` on the active tab, so `aria-current` is not needed.
