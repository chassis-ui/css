## Introduction

Avatars represent a user or an entity as a picture or as short text, such as initials. An avatar is an inline element of equal width and height, round by default, that can carry a status badge and join other avatars in an overlapping stack.

## Basic structure

Add the `.avatar` class to an element that holds short text, which is rendered in uppercase, or an `<img>` with the `.avatar-image` class, which fills the avatar and takes its radius.

<Example code={`<span class="avatar">CX</span>
  <span class="avatar">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture" />
  </span>`} />

## Sizes

Use the <Fragment set:html={ getData('sizes').map((size) => `<code>.${size}</code>`).join(', ') } /> classes to set the size of the avatar, or set the `--cx-avatar-size` custom property for a custom size. The font size of a text avatar scales with it.

<Example class="d-flex align-items-center gap-sm" code={[
  ...getData('sizes').map((size) => `<span class="avatar ${size}">CX</span>`),
  `<span class="vr mx-md"></span>`,
  `<span class="avatar" style="--cx-avatar-size: 1.75rem;">CX</span>
  <span class="avatar" style="--cx-avatar-size: 4.25rem;">CX</span>`
]} />

<Example class="d-flex align-items-center gap-sm" code={[
  ...getData('sizes').map((size) => `<span class="avatar ${size}"><img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/></span>`),
  `<span class="vr mx-md"></span>`,
  `<span class="avatar" style="--cx-avatar-size: 1.75rem;"><img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/></span>
  <span class="avatar" style="--cx-avatar-size: 4.25rem;"><img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/></span>`
]} />

## Buttons

Add the `.avatar` class to a `<button>` element for an avatar that triggers an action. The avatar shows the focus ring on keyboard focus and is dimmed when disabled.

<Example class="d-flex align-items-center gap-sm" code={`<button class="avatar" type="button">CX</button>
  <button class="avatar" type="button">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/>
  </button>`} />

## Links

Add the `.avatar` class to an `<a>` element for an avatar that navigates, to a profile page for example.

<Example class="d-flex align-items-center gap-sm" code={`<a class="avatar" href="#">CX</a>
  <a class="avatar" href="#">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/>
  </a>`} />

## Colors

Add a context color class, such as `.primary`, to color a text avatar from that context. The `.smooth` class next to it switches to the subdued colors of the context.

<Example class="d-flex align-items-center gap-sm" code={getData('context-colors').map((color) => `<button class="avatar ${color.name}" type="button">CX</button>`)} />

<Example class="d-flex align-items-center gap-sm" code={getData('context-colors').map((color) => `<button class="avatar smooth ${color.name}" type="button">CX</button>`)} />

## Badges

A `.badge` placed inside an avatar becomes a status indicator at its bottom end corner, with no position utilities needed. Give the badge visually hidden text, since its color alone does not convey the status to assistive technology.

<Example class="d-flex align-items-center gap-sm" code={`<button class="avatar" type="button">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/>
    <span class="badge success circle"><span class="visually-hidden">Online</span></span>
  </button>
  <button class="avatar" type="button">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/>
    <span class="badge danger circle"><span class="visually-hidden">Offline</span></span>
  </button>
  <button class="avatar" type="button">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/>
    <span class="badge warning circle"><span class="visually-hidden">Away</span></span>
  </button>
  <button class="avatar" type="button">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/>
    <span class="badge neutral circle"><span class="visually-hidden">Busy</span></span>
  </button>`} />

The badge is a quarter of the avatar size, so it scales with every avatar size.

<Example class="d-flex align-items-center gap-sm" code={[
  ...getData('sizes').map((size) => `<button class="avatar ${size}" type="button">
    <img class="avatar-image" src="https://i.pravatar.cc/256" alt="Profile picture"/>
    <span class="badge success circle"><span class="visually-hidden">Online</span></span>
  </button>`)]} />

## Stacks

Wrap avatars in an `.avatar-stack` element to group them with an overlap. The `--cx-avatar-stack-spacing` custom property sets the overlap as a fraction of the avatar size, and an interactive avatar of a stack is raised and enlarged on hover and keyboard focus.

<Example code={[`<div class="avatar-stack">`, 
  [...Array.from({ length: 9 }, (_, i) => {
    const value = Math.floor(Math.random() * 64); // Generates 10, 20, ..., 90
    return `  <button class="avatar" type="button">
      <img class="avatar-image" src="https://i.pravatar.cc/256?img=${value}" alt="Profile picture"/>
    </button>`})].join('\n'),
  `  <button class="avatar" type="button">+5</button>
  </div>`]} />

A size class on the stack sets the size of all its avatars.

<Example class="vstack gap-sm" code={[
  ...getData('sizes').map((size) => `<div class="avatar-stack ${size}">
    ${[...Array.from({ length: 4 }, (_, i) => {
      const value = Math.floor(Math.random() * 64); // Generates 10, 20, ..., 90
      return `<button class="avatar" type="button">
      <img class="avatar-image" src="https://i.pravatar.cc/256?img=${value}" alt="Profile picture"/>
    </button>`})].join('\n')}
    <button class="avatar" type="button">+5</button>
  </div>`)
]} />
