## Introduction

Buttons trigger actions and navigation. The `.button` class sets layout, typography, and interactive states, and takes its sizes and colors from the button design tokens, so a button in code matches its counterpart in the Figma library. Context classes set the color, and the `.outline`, `.smooth`, and `.link` modifiers set the style.

## Basic structure

Apply `.button` to a `<button>` element. The class alone renders a button on the body colors; a context class such as `.default` or `.primary` sets its color, and `.link` renders it as a link.

<Example class="button-examples" code={`<button type="button" class="button">Foundation class</button>
<button type="button" class="button default">Default Button</button>
<button type="button" class="button primary">Primary Button</button>
<button type="button" class="button link">Link</button>`} />

<Callout type="info">
  <strong>Accessibility:</strong> The `.button` class includes a focus ring that shows on keyboard focus.
</Callout>

## Button variants

Add a context class to `.button` to color it. Each context maps to a set of design tokens, and a button without a style modifier is solid.

<Example class="button-examples" code={[...getData('context-colors').map((contextColor) => `<button type="button" class="button ${contextColor.name}">${contextColor.title}</button>`)]} />

<Callout name="warning-color-assistive-technologies" />

### Outline variants

The `.outline` modifier renders a button with a border and a transparent background in the colors of its context.

<Example class="button-examples" code={[...getData('context-colors').map((contextColor) => `<button type="button" class="button ${contextColor.name} outline">${contextColor.title}</button>`)]} />

<Callout>
  Some outline variants use a light foreground color and need a dark background to keep enough contrast.
</Callout>

### Smooth variants

The `.smooth` modifier renders a button with a subdued background in the colors of its context.

<Example class="button-examples" code={[...getData('context-colors').map((contextColor) => `<button type="button" class="button ${contextColor.name} smooth">${contextColor.title}</button>`)]} />

### Link buttons

The `.link` modifier removes the background and border and renders the button text in the link color of its context.

<Example class="button-examples" code={[...getData('context-colors').map((contextColor) => `<button type="button" class="button ${contextColor.name} link">${contextColor.title}</button>`)]} />

## Element compatibility

The `.button` classes are written for the `<button>` element and also apply to `<a>` and `<input>` elements.

<Example class="button-examples" code={`<button class="button primary" type="submit">Button</button>
<input class="button primary" type="button" value="Input">
<input class="button primary" type="submit" value="Submit">
<input class="button primary" type="reset" value="Reset">
<a class="button primary" href="#">Link</a>`} />

Add `role="button"` to an `<a>` element that triggers in-page functionality instead of navigating, so assistive technologies announce it as a button.

## Icons

Place an icon before or after the button text. Both SVG icons and icon fonts work.

<Example class="button-examples" code={`<button type="button" class="button default">
    <Icon name="info-circle-solid" role="img" />
    <span>Default</span>
  </button>
  <button type="button" class="button primary">
    <Icon name="info-circle-solid" role="img" />
    <span>Primary</span>
  </button>
  <button type="button" class="button default">
    <span>Default</span>
    <Icon name="info-circle-solid" font />
  </button>
  <button type="button" class="button primary">
    <span>Primary</span>
    <Icon name="info-circle-solid" font />
  </button>`} />

<Callout type="warning">
  Icon spacing relies on the `:first-child` and `:last-child` pseudo-classes. Wrap the button text in a `<span>` element so the icon is matched as the first or last child.
</Callout>

### Icon-only buttons

Add `.icon-only` to a button whose only content is an icon. The modifier sets the horizontal padding to the vertical padding, which makes the button square. Give the button an `aria-label`, since it has no visible text.

<Example class="button-examples" code={`<button type="button" class="button default icon-only" aria-label="Info">
    <Icon name="info-circle-solid" role="img" />
  </button>
  <button type="button" class="button primary icon-only" aria-label="Info">
    <Icon name="info-circle-solid" role="img" />
  </button>
  <button type="button" class="button sm default icon-only" aria-label="Info">
    <Icon name="info-circle-solid" font />
  </button>
  <button type="button" class="button sm primary icon-only" aria-label="Info">
    <Icon name="info-circle-solid" font />
  </button>
  <button type="button" class="button lg default icon-only" aria-label="Info">
    <Icon name="info-circle-solid" font />
  </button>
  <button type="button" class="button default lg icon-only" aria-label="Info">
    <Icon name="info-circle-solid" role="img" />
  </button>
  <button type="button" class="button lg primary icon-only" aria-label="Info">
    <Icon name="info-circle-solid" font />
  </button>`} />

## Size variants

Buttons come in three sizes. Add `.lg` or `.sm` for the large or small size; the medium size applies without a modifier.

<Example class="button-examples" code={`<button type="button" class="button default lg">
    Default
  </button>
  <button type="button" class="button default lg">
    <Icon name="info-circle-solid" role="img" />
    <span>Default</span>
  </button>
  <button type="button" class="button primary lg">
    Primary
  </button>
  <button type="button" class="button primary lg">
    <Icon name="info-circle-solid" role="img" />
    <span>Primary</span>
  </button>`} />

<Example class="button-examples" code={`<button type="button" class="button default sm">
    Default
  </button>
  <button type="button" class="button default sm">
    <Icon name="info-circle-solid" role="img" />
    <span>Default</span>
  </button>
  <button type="button" class="button primary sm">
    Primary
  </button>
  <button type="button" class="button primary sm">
    <Icon name="info-circle-solid" role="img" />
    <span>Primary</span>
  </button>`} />

### Custom sizing

For a size outside the three variants, set the sizing custom properties of the button, such as `--cx-button-padding-y`, `--cx-button-padding-x`, and `--cx-button-font-size`.

<Example class="button-examples" code={`<button type="button" class="button primary"
    style="--cx-button-padding-y: .75rem; --cx-button-padding-x: 1.5rem; --cx-button-font-size: .75rem;">
    Custom-sized button
  </button>`} />

## Disabled state

Add the `disabled` attribute to a `<button>` element to disable it. A disabled button takes the disabled colors of its variant and ignores pointer events.

<Example class="button-examples" code={`<button type="button" class="button default" disabled>
    <Icon name="info-circle-solid" role="img" />
    <span>Default Button</span>
  </button>
  <button type="button" class="button default outline" disabled>
    <Icon name="info-circle-solid" role="img" />
    <span>Default button</span>
  </button>
  <button type="button" class="button default smooth" disabled>
    <Icon name="info-circle-solid" role="img" />
    <span>Default button</span>
  </button>
  <button type="button" class="button primary" disabled>
    <Icon name="info-circle-solid" role="img" />
    <span>Primary Button</span>
  </button>
  <button type="button" class="button primary outline" disabled>
    <Icon name="info-circle-solid" role="img" />
    <span>Primary Button</span>
  </button>
  <button type="button" class="button primary smooth" disabled>
    <Icon name="info-circle-solid" role="img" />
    <span>Primary Button</span>
  </button>`} />

The `<a>` element has no `disabled` attribute, so a link button takes the `.disabled` class and `aria-disabled="true"` instead.

<Example class="button-examples" code={`<a class="button default disabled" role="button" aria-disabled="true">Default Link</a>
<a class="button primary disabled" role="button" aria-disabled="true">Primary Link</a>
<a class="button secondary disabled" role="button" aria-disabled="true">Secondary Link</a>`} />

### Disabled links

A disabled link button needs three things:

1. The `.disabled` class, which applies the disabled styles.
2. `aria-disabled="true"`, which communicates the state to assistive technologies.
3. No `href` attribute where possible, which prevents navigation.

When the `href` attribute must stay, add `tabindex="-1"`:

<Example class="button-examples" code={`<a href="#" class="button default disabled" tabindex="-1" role="button" aria-disabled="true">Default Link</a>
<a href="#" class="button primary disabled" tabindex="-1" role="button" aria-disabled="true">Primary Link</a>
<a href="#" class="button secondary disabled" tabindex="-1" role="button" aria-disabled="true">Secondary Link</a>`} />

The `.disabled` class applies `pointer-events: none`, which stops pointer interaction only. The link stays reachable by keyboard, so `tabindex="-1"` removes it from the tab order, and custom JavaScript is needed to disable its functionality completely.

## Layout patterns

Buttons have no container classes of their own. Display, gap, sizing, and flex utilities on a wrapper control their spacing, alignment, and responsive behavior.

### Full-width buttons

Wrap buttons in an element with `.d-grid` to stack them at the full width of the wrapper, and add a gap utility for spacing.

<Example class="button-examples" code={`<div class="d-grid gap-xs">
    <button class="button default" type="button">Default</button>
    <button class="button primary" type="button">Primary</button>
  </div>`} />

### Responsive buttons

Add a responsive display utility to change the layout at a breakpoint. With `.md:d-block` the buttons stack up to the `md` breakpoint and sit inline from there.

<Example class="button-examples" code={`<div class="d-grid gap-xs md:d-block">
    <button class="button default" type="button">Default</button>
    <button class="button primary" type="button">Primary</button>
  </div>`} />

### Width control

Apply a [width utility]([[docsref:/utilities/sizing]]) to the wrapper to limit the width of the stacked buttons.

<Example class="button-examples" code={`<div class="d-grid gap-xs w-6/12 mx-auto">
    <button class="button default" type="button">Default</button>
    <button class="button primary" type="button">Primary</button>
  </div>`} />

### Alignment control

Combine responsive display and [flex utilities]([[docsref:/utilities/flex]]) to align the buttons inside the wrapper.

<Example class="button-examples" code={`<div class="d-grid gap-xs md:d-flex md:justify-content-end">
    <button class="button default" type="button">Default</button>
    <button class="button primary" type="button">Primary</button>
  </div>`} />

## Text handling

The `$button-white-space` Sass variable sets the `white-space` of every button. Its default is `nowrap`, which keeps button text on one line; set it to `null` to let button text wrap inside its container. In a build with wrapping buttons, the `.text-nowrap` utility keeps a single button on one line.

<Example class="button-examples" code={`<div style="max-width: 200px;">
    <p><button type="button" class="button primary">Button with a longer text that will wrap</button></p>
    <p><button type="button" class="button primary text-nowrap">While no-wrap text will extend beyond boundaries</button></p>
  </div>`} />

## Toggle functionality

The Button plugin turns a button into a toggle that keeps its pressed state. Assistive technologies announce a toggle button as "button"/"button pressed", where a checkbox toggle is announced as "checked"/"not checked".

### Toggle states

Add `data-cx-toggle="button"` to make a button a toggle. Each click toggles the `.active` class and keeps `aria-pressed` in sync. For a button that starts pressed, add both the `.active` class and `aria-pressed="true"`.

<Example class="button-examples" code={`<p class="d-inline-flex gap-xs">
    <button type="button" class="button default" data-cx-toggle="button" aria-pressed="false">Toggle button</button>
    <button type="button" class="button default active" data-cx-toggle="button" aria-pressed="true">Active toggle</button>
    <button type="button" class="button default" disabled data-cx-toggle="button" aria-pressed="false">Disabled toggle</button>
    <button type="button" class="button default active" disabled data-cx-toggle="button" aria-pressed="true">Disabled active</button>
  </p>
  <p class="d-inline-flex gap-xs">
    <button type="button" class="button primary" data-cx-toggle="button" aria-pressed="false">Toggle button</button>
    <button type="button" class="button primary active" data-cx-toggle="button" aria-pressed="true">Active toggle</button>
    <button type="button" class="button primary" disabled data-cx-toggle="button" aria-pressed="false">Disabled toggle</button>
    <button type="button" class="button primary active" disabled data-cx-toggle="button" aria-pressed="true">Disabled active</button>
  </p>`} />

Link buttons toggle the same way. Add `role="button"` so the pressed state is announced.

<Example class="button-examples" code={`<p class="d-inline-flex gap-xs">
    <a href="#" class="button default" role="button" data-cx-toggle="button" aria-pressed="false">Toggle link</a>
    <a href="#" class="button default active" role="button" data-cx-toggle="button" aria-pressed="true">Active toggle</a>
    <a href="#" class="button default disabled" aria-disabled="true" role="button" data-cx-toggle="button" aria-pressed="false">Disabled toggle</a>
    <a href="#" class="button default active disabled" aria-disabled="true" role="button" data-cx-toggle="button" aria-pressed="true">Disabled active</a>
  </p>
  <p class="d-inline-flex gap-xs">
    <a href="#" class="button primary" role="button" data-cx-toggle="button" aria-pressed="false">Toggle link</a>
    <a href="#" class="button primary active" role="button" data-cx-toggle="button" aria-pressed="true">Active toggle</a>
    <a href="#" class="button primary disabled" aria-disabled="true" role="button" data-cx-toggle="button" aria-pressed="false">Disabled toggle</a>
    <a href="#" class="button primary active disabled" aria-disabled="true" role="button" data-cx-toggle="button" aria-pressed="true">Disabled active</a>
  </p>`} />

## JavaScript API

The Button plugin toggles the pressed state of a button. Chassis JS ships as an ES module — import the `Button` class:

```js
import { Button } from '@chassis-ui/css'
```

### Triggers

The data-attribute API needs no JavaScript beyond the plugin itself. A click on an element with `data-cx-toggle="button"` toggles it, as shown in [Toggle functionality](#toggle-functionality):

```html
<button type="button" class="button default" data-cx-toggle="button" aria-pressed="false">Toggle button</button>
```

### Initialization

For programmatic access, create an instance with the `Button` class:

```js
const button = new Button('#myButton')
```

### Methods

The plugin exposes one instance method of its own, next to the methods every Chassis plugin has:

<CxTable>
| Method | Description |
| --- | --- |
| `toggle` | Toggles the `.active` class of the button and sets `aria-pressed` to match. |
| `dispose` | Destroys the instance and removes its stored data from the element. |
| `getInstance` | Static — returns the instance bound to a DOM element, or `null`: `Button.getInstance(element)`. |
| `getOrCreateInstance` | Static — returns the instance bound to a DOM element, or creates one: `Button.getOrCreateInstance(element)`. |
</CxTable>

`getOrCreateInstance` toggles a set of buttons without tracking their instances:

```js
document.querySelectorAll('[data-cx-toggle="button"]').forEach(element => {
  Button.getOrCreateInstance(element).toggle()
})
```
