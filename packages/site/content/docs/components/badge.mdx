## Introduction

Badges are small inline labels that add a count, a tag, or a status indicator to content. They highlight new items, display notification counts, and sit inside other components such as buttons and avatars. A badge takes its color from a context class and comes in three styles and three sizes.

## Basic structure

Add the `.badge` class to an element to render it as a badge. Without a context class the badge takes the colors of the context around it, and the `.circle` modifier gives it equal width and height for a short count.

<Example code={`<!-- Base class -->
<span class="badge">Base</span>
<span class="badge">24</span>
<span class="badge circle">24</span>

<!-- Default variant -->
<span class="badge default">Default</span>
<span class="badge default">24</span>
<span class="badge default circle">24</span>

<!-- Primary variant -->
<span class="badge primary">Primary</span>
<span class="badge primary">24</span>
<span class="badge primary circle">24</span>`} />

### Badge elements

The `.badge` class works on any inline or block element, links included, and always renders as an inline flex box.

<Example code={`<span class="badge primary">Span</span>
<a class="badge primary" href="#">Link</a>
<div class="badge primary">Div</div>`} />

## Color variants

The default badge style is solid: the background color of the context with contrasting text. Add a context color class, such as `.primary` or `.secondary`, next to `.badge` to choose the context.

<Example code={getData('context-colors').map((contextColor) => `<span class="badge ${contextColor.name}">${contextColor.title}</span>`)} />

<Callout name="warning-color-assistive-technologies" />

### Outline style

Add the `.outline` class for a badge with a transparent background and a border and text in the context color.

<Example code={getData('context-colors').map((contextColor) => `<span class="badge ${contextColor.name} outline">${contextColor.title}</span>`)} />

### Smooth style

Add the `.smooth` class for a badge with a subdued background of the context color and matching text.

<Example code={getData('context-colors').map((contextColor) => `<span class="badge ${contextColor.name} smooth">${contextColor.title}</span>`)} />

## Size variants

Badges come in three sizes. The `.sm` and `.lg` classes change the paddings, the font size, the radius and the icon size; the medium size needs no class.

<Example code={`<span class="badge sm primary">Small</span>
  <span class="badge primary">Medium</span>
  <span class="badge lg primary">Large</span>

  <span class="badge sm circle primary">2</span>
  <span class="badge circle primary">2</span>
  <span class="badge lg circle primary">2</span>`} />

## Icons

A badge can hold an icon before or after its text, either an SVG icon or an icon font. The icon takes the icon size of the badge size.

<Example code={`<span class="badge default sm">
    <Icon name="info-circle-solid" role="img" />
    <span>Small</span>
  </span>
  <span class="badge default">
    <Icon name="info-circle-solid" role="img" />
    <span>Medium</span>
  </span>
  <span class="badge default lg">
    <Icon name="info-circle-solid" role="img" />
    <span>Large</span>
  </span>

  <span class="badge primary sm">
    <span>Small</span>
    <Icon name="info-circle-solid" font />
  </span>
  <span class="badge primary">
    <span>Medium</span>
    <Icon name="info-circle-solid" font />
  </span>
  <span class="badge primary lg">
    <span>Large</span>
    <Icon name="info-circle-solid" font />
  </span>`} />

<Callout type="warning">
  The spacing of an icon comes from the `:first-child` and `:last-child` selectors. Wrap the badge text in a `<span>` element so that the icon is matched as the first or last child.
</Callout>

## Use cases

Badges combine with other components and with utilities for counters, notification indicators and custom shapes.

### With components

Place a badge inside a button or another component to show a count or a status next to its label.

<Example code={`<button type="button" class="button primary">
    Notifications
    <span class="badge secondary circle" role="status"
     aria-label="new notifications">2</span>
  </button>`} />

Unless the surrounding content makes the meaning of a badge clear, add visually hidden text that explains it.

<Callout type="warning">
  A bare number or dot gives screen reader users no context. Add `role="status"` to a counter that updates, so that changes are announced, and `role="presentation"` to a decorative badge. Explain the meaning of a badge with `aria-label` or with a `<span class="visually-hidden">` inside it.
</Callout>

### Positioned badges

The [position utilities]([[docsref:/utilities/position]]) place a badge on the corner of an element, as a notification indicator.

<Example code={`<button type="button" class="button primary position-relative">
    Inbox
    <span class="badge secondary position-absolute top-0 start-100 translate-middle">
      99+ <span class="visually-hidden">unread messages</span>
    </span>
  </button>`} />

A badge with only visually hidden text and a padding utility renders as an indicator dot.

<Example code={`<button type="button" class="button primary position-relative">
    Profile
    <span class="badge secondary p-xs rounded-full
      position-absolute top-0 start-100 translate-middle">
      <span class="visually-hidden">New alerts</span>
    </span>
  </button>`} />

### Custom corners

The [border-radius utilities]([[docsref:/utilities/borders#radius]]) override the default radius of a badge, from square corners to a pill, while the paddings and the typography stay the same.

<Example code={`<span class="badge primary rounded-zero">Sharp</span>
<span class="badge primary rounded-sm">Blunt</span>
<span class="badge primary rounded-md">Soft</span>
<span class="badge primary rounded-full">Pill</span>`} />

## Adaptive sizing

The `.badge-adaptive` class sizes a badge in `em` units, so its font size, paddings and icon size follow the font size of the parent element. The same badge then fits headings and body text of any size, while a badge with a size class keeps its fixed size.

<Example code={`<h3>
    Example heading
    <span class="badge primary badge-adaptive">Adaptive</span>
    <span class="badge primary lg">Large</span>
  </h3>
  <hr>
  <p class="font-xs">
    Extra small paragraph
    <span class="badge primary badge-adaptive">Adaptive</span>
    <span class="badge primary sm">Small</span>
  </p>`} />

### With wrappers

Add `.badge-adaptive` to a wrapper to give every badge inside it adaptive sizing.

<Example code={`<div class="badge-adaptive">
    <p class="font-h1">Example heading <span class="badge primary">New</span></p>
    <p class="font-h2">Example heading <span class="badge primary">New</span></p>
    <p class="font-h3">Example heading <span class="badge primary">New</span></p>
    <p class="font-h4">Example heading <span class="badge primary">New</span></p>
    <p class="font-h5">Example heading <span class="badge primary">New</span></p>
    <p class="font-h6">Example heading <span class="badge primary">New</span></p>
  </div>`}
  customMarkup={`<div class="badge-adaptive">
    <h1>Example heading <span class="badge primary">New</span></h1>
    <h2>Example heading <span class="badge primary">New</span></h2>
    <h3>Example heading <span class="badge primary">New</span></h3>
    <h4>Example heading <span class="badge primary">New</span></h4>
    <h5>Example heading <span class="badge primary">New</span></h5>
    <h6>Example heading <span class="badge primary">New</span></h6>
  </div>`} />
