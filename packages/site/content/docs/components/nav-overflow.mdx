## Introduction

Nav overflow, also known as the Priority+ pattern, detects the items of a [nav]([[docsref:/components/nav]]) that do not fit within their container and moves them into a [menu]([[docsref:/components/menu]]). One set of markup then serves every container width.

### How it works

The plugin measures a wrapper around the nav and decides which items fit:

- The `.nav-overflow` wrapper is the element the plugin measures. Collapsing items changes the width of the nav, so measuring the nav itself would feed the result back in as the input.
- The plugin responds to the size of the wrapper, not of the viewport. It watches the wrapper with a `ResizeObserver`, so it also works in sidebars, embedded contexts, and resizable containers.
- The links of the items that overflow are cloned into a "More" menu, and the original items are hidden.
- Every nav style is supported: default, tabs, segments, and underline.
- Active and disabled states are preserved in the overflow menu.

<Callout name="info-prefersreducedmotion" />

## Customizing the toggle

The toggle that opens the overflow menu shows an icon followed by the text "More". The options of the plugin change the text, the icon, and their order.

### Custom text

Set the `moreText` option to change the text of the toggle:

```js
import { NavOverflow } from '@chassis-ui/css'

const nav = document.querySelector('.nav-overflow')
new NavOverflow(nav, {
  moreText: 'See all'
})
```

### Custom icon

Set the `moreIcon` option to change the icon. Any HTML string is accepted, including an inline SVG; the plugin sanitizes it before inserting it:

```js
const nav = document.querySelector('.nav-overflow')
new NavOverflow(nav, {
  moreIcon: '<svg xmlns="http://www.w3.org/2000/svg" width="16" height="16" fill="currentColor" viewBox="0 0 16 16"><path d="M3 9.5a1.5 1.5 0 1 1 0-3 1.5 1.5 0 0 1 0 3m5 0a1.5 1.5 0 1 1 0-3 1.5 1.5 0 0 1 0 3m5 0a1.5 1.5 0 1 1 0-3 1.5 1.5 0 0 1 0 3"/></svg>',
  moreText: false // Icon-only toggle; falls back to an aria-label of "More"
})
```

Alternatively, place an element with `data-cx-overflow-icon` inside the wrapper. The plugin uses it as the toggle icon and removes the original element from the DOM until `dispose` puts it back. This element takes priority over the `moreIcon` option.

```html
<div class="nav-overflow" data-cx-toggle="nav-overflow">
  <ul class="nav nav-segments">
    <li class="nav-item"><a class="nav-link" href="#">Link 1</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Link 2</a></li>
    <svg data-cx-overflow-icon xmlns="http://www.w3.org/2000/svg" width="16" height="16" fill="currentColor" viewBox="0 0 16 16">
      <path d="M8 4.754a3.246 3.246 0 1 0 0 6.492 3.246 3.246 0 0 0 0-6.492"/>
    </svg>
  </ul>
</div>
```

### Icon placement

Set the `iconPlacement` option to place the icon before the text (`'start'`, the default) or after it (`'end'`):

```js
const nav = document.querySelector('.nav-overflow')
new NavOverflow(nav, {
  moreText: 'Menu',
  iconPlacement: 'end'
})
```

## Collapse behavior

By default, items collapse one by one from the end of the nav as the wrapper narrows. Two options change when items collapse.

### Minimum visible items

Set the `threshold` option to keep a minimum number of items visible:

```js
import { NavOverflow } from '@chassis-ui/css'

const nav = document.querySelector('.nav-overflow')
new NavOverflow(nav, {
  threshold: 3 // Always keep at least 3 items visible
})
```

### Collapse all

Set the `collapseBelow` option to move every item into the overflow menu while the wrapper is narrower than a given width. Pass a breakpoint name to resolve the width from `--cx-breakpoint-{name}`, or a number for a width in pixels.

```html
<div class="nav-overflow" data-cx-toggle="nav-overflow" data-cx-collapse-below="md">
  <ul class="nav nav-segments">
    <li class="nav-item"><a class="nav-link" href="#">Link 1</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Link 2</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Link 3</a></li>
  </ul>
</div>
```

The same option takes a width in pixels through JavaScript:

```js
const nav = document.querySelector('.nav-overflow')
new NavOverflow(nav, {
  collapseBelow: 768
})
```

At and above that width, items collapse one by one again. Items with `.nav-overflow-keep` are never collapsed.

## Accessibility

The toggle the plugin builds is a `<button>` with `aria-expanded`, and the [Menu plugin]([[docsref:/components/menu#javascript-api]]) opens the overflow menu and handles its keyboard interaction. An icon-only toggle (`moreText: false`) gets `aria-label="More"`, so it keeps an accessible name.

An item that overflows is hidden with `display: none`, and a copy of its link, with its attributes, is added to the menu. Each link is therefore exposed to assistive technologies once, and `aria-current` and `aria-disabled` travel with it.

## JavaScript API

The NavOverflow plugin measures the wrapper, moves items between the nav and the overflow menu, and fires events as it does. Import the `NavOverflow` class from the Chassis module:

```js
import { NavOverflow } from '@chassis-ui/css'
```

### Triggers

The data-attribute API enables the overflow behavior without any JavaScript on the page beyond the bundled plugin. The plugin initializes every wrapper with the attribute when the page has loaded:

<CxTable>
| Attribute | Description |
| --- | --- |
| `data-cx-toggle="nav-overflow"` | Enables overflow handling on the `.nav-overflow` wrapper. |
</CxTable>

```html
<div class="nav-overflow" data-cx-toggle="nav-overflow">
  <ul class="nav nav-segments">
    <li class="nav-item"><a class="nav-link" href="#">Link 1</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Link 2</a></li>
    <li class="nav-item"><a class="nav-link" href="#">Link 3</a></li>
    <!-- More items... -->
  </ul>
</div>
```

### Initialization

For programmatic control, or for a wrapper added after the page has loaded, instantiate the wrapper with the `NavOverflow` class. The wrapper must contain a `.nav`; the constructor throws a `TypeError` otherwise.

```js
const wrapperElement = document.querySelector('.nav-overflow')
const navOverflow = new NavOverflow(wrapperElement, {
  moreText: 'More',
  threshold: 2
})
```

### Options

<JsDataAttributes />

<CxTable>
| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `collapseBelow` | number\|string | `0` | Width of the wrapper below which all items collapse into the overflow menu. Pass a breakpoint name (e.g., `'md'`) to resolve from `--cx-breakpoint-{name}`, or a number for a width in pixels. `0` disables. |
| `iconPlacement` | string | `'start'` | Position of the icon relative to the text in the toggle button. Use `'start'` for before the text or `'end'` for after. |
| `menuPlacement` | string | `'bottom-end'` | Placement of the overflow menu, passed as `data-cx-placement` to the menu toggle. |
| `moreText` | string\|boolean | `'More'` | Text label for the overflow toggle button. Pass `false` for an icon-only toggle; the button falls back to `aria-label="More"` so it keeps an accessible name. |
| `moreIcon` | string | `'<svg>...</svg>'` | SVG or HTML icon for the overflow toggle button. Overridden by a child element with `data-cx-overflow-icon` if present. |
| `threshold` | number | `0` | Minimum number of items to keep visible before showing overflow. |
</CxTable>

### Methods

The plugin exposes two instance methods and two static lookup methods for programmatic control:

<CxTable>
| Method | Description |
| --- | --- |
| `dispose` | Destroys the instance and restores the items to their original positions. A toggle the plugin built is removed; a toggle, menu or icon element written in the markup stays where it was. |
| `getInstance` | *Static* — returns the existing instance bound to a DOM element, or `null`. Example: `NavOverflow.getInstance(element)` |
| `getOrCreateInstance` | *Static* — returns the existing instance or creates one. Example: `NavOverflow.getOrCreateInstance(element)` |
| `update` | Recalculates which items overflow. The plugin recalculates by itself when the wrapper resizes; call `update` after a change that alters the width of the items without resizing the wrapper, such as a changed label. |
</CxTable>

### Events

The events fire on the `.nav-overflow` wrapper and report each overflow calculation.

<CxTable>
| Event | Description |
| --- | --- |
| `update.cx.navoverflow` | Fired after `update()` recalculates the overflow. |
| `overflow.cx.navoverflow` | Fired after a calculation that leaves items in the overflow menu, on resize or on `update()`. The event has the `overflowCount` and `visibleCount` properties. |
</CxTable>

```js
const myNav = document.getElementById('myNav')

myNav.addEventListener('overflow.cx.navoverflow', event => {
  console.log(`${event.overflowCount} items moved to overflow`)
  console.log(`${event.visibleCount} items still visible`)
})
```
