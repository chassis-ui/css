## Introduction

Lists group a series of related items in a bordered container. Items are plain content by default, and become actionable as links or buttons, hold custom content and other components, and take the context colors.

## Basic structure

A list is an element with the `.list` class, typically a `<ul>`, and a `.list-item` for each entry. The container sets the custom properties of the component, and the items draw the borders, the padding and the rounded outer corners.

<Example code={`<ul class="list">
    <li class="list-item">An item</li>
    <li class="list-item">A second item</li>
    <li class="list-item">A third item</li>
    <li class="list-item">A fourth item</li>
    <li class="list-item">And a fifth one</li>
  </ul>`} />

### Active state

Apply the `.active` class to a `.list-item` to mark the current selection. Add `aria-current="true"` so assistive technologies announce the active item.

<Example code={`<ul class="list">
    <li class="list-item active" aria-current="true">An active item</li>
    <li class="list-item">A second item</li>
    <li class="list-item">A third item</li>
    <li class="list-item">A fourth item</li>
    <li class="list-item">And a fifth one</li>
  </ul>`} />

### Disabled state

Apply the `.disabled` class to a `.list-item` to style it as disabled. Add `aria-disabled="true"` to convey the state to assistive technologies.

<Callout type="warning">
  The `.disabled` class changes the appearance and sets `pointer-events: none`. A link stays reachable and operable with the keyboard: omit its `href`, or prevent its activation with JavaScript.
</Callout>

<Example code={`<ul class="list">
    <li class="list-item disabled" aria-disabled="true">A disabled item</li>
    <li class="list-item">A second item</li>
    <li class="list-item">A third item</li>
    <li class="list-item">A fourth item</li>
    <li class="list-item">And a fifth one</li>
  </ul>`} />

## Interactive elements

Use `<a>` or `<button>` elements with the `.list-action` class for actionable items. The class adds the hover, focus, pressed and disabled states to an item, on a single `.list-item` or on the `.list` for all of its items.

The interactive states are opt-in, so items that are not links or buttons give no hover feedback and read-only content is not mistaken for an action.

<Example code={`<div class="list">
    <a href="#" class="list-item list-action active" aria-current="true">
      The current link item
    </a>
    <a href="#" class="list-item list-action">A second link item</a>
    <a href="#" class="list-item list-action">A third link item</a>
    <a href="#" class="list-item list-action">A fourth link item</a>
    <a class="list-item list-action disabled" aria-disabled="true">A disabled link item</a>
  </div>`} />

### Links vs buttons

Anchors and buttons both work as actionable list items, and differ in meaning:

- Use `<a>` elements when the action navigates to a new location or resource
- Use `<button>` elements when the action triggers an in-page behavior or state change

<Callout type="info">
  A `<button>` takes the native `disabled` attribute, which styles the item and prevents interaction. An `<a>` has no such attribute: the `.disabled` class styles it, and omitting `href` keeps it out of the tab order.
</Callout>

<Example code={`<div class="list">
    <button type="button" class="list-item list-action active" aria-current="true">
      The current button
    </button>
    <button type="button" class="list-item list-action">A second button item</button>
    <button type="button" class="list-item list-action">A third button item</button>
    <button type="button" class="list-item list-action">A fourth button item</button>
    <button type="button" class="list-item list-action" disabled>A disabled button item</button>
  </div>`} />

## Layout options

Modifier classes on the `.list` element change its borders, its padding, its numbering and the direction of its items.

### Flush list

Apply `.flush` to remove the outer borders and the rounded corners, so the items run edge to edge. It suits a list inside another component, such as a card.

<Example code={`<ul class="list flush">
    <li class="list-item">An item</li>
    <li class="list-item">A second item</li>
    <li class="list-item">A third item</li>
    <li class="list-item">A fourth item</li>
    <li class="list-item">And a fifth one</li>
  </ul>`} />

### Plain layout

Apply `.plain` to remove the outer borders, the rounded corners and the horizontal padding. It suits a list that is the main content of a page, such as search results or a feed.

<Example code={`<ul class="list plain">
    <li class="list-item">An item</li>
    <li class="list-item">A second item</li>
    <li class="list-item">A third item</li>
    <li class="list-item">A fourth item</li>
    <li class="list-item">And a fifth one</li>
  </ul>`} />

<Callout type="info">
  Both `.flush` and `.plain` remove the outer borders and the rounded corners. `.plain` also removes the horizontal padding of the items.
</Callout>

### Numbered lists

Apply `.numbered` to number the items of a list. Use an `<ol>` element for the semantics: the numbers themselves are generated with CSS, not by the browser's list markers.

<Callout type="info">
  The numbering uses CSS counters: `counter-reset` on the `.list` element, and a `::before` pseudo-element with `counter-increment` on each item. The number is part of the item's content box, so it stays in place next to content of any complexity.
</Callout>

<Example code={`<ol class="list numbered">
    <li class="list-item">A list item</li>
    <li class="list-item">A list item</li>
    <li class="list-item">A list item</li>
  </ol>`} />

Numbered items hold custom content as well, here laid out with flex utilities.

<Example code={`<ol class="list numbered">
    <li class="list-item d-flex justify-content-between align-items-start">
      <div class="ms-xs me-auto">
        <div class="font-strong">Subheading</div>
        Content for list item
      </div>
      <span class="badge primary">14</span>
    </li>
    <li class="list-item d-flex justify-content-between align-items-start">
      <div class="ms-xs me-auto">
        <div class="font-strong">Subheading</div>
        Content for list item
      </div>
      <span class="badge primary">14</span>
    </li>
    <li class="list-item d-flex justify-content-between align-items-start">
      <div class="ms-xs me-auto">
        <div class="font-strong">Subheading</div>
        Content for list item
      </div>
      <span class="badge primary">14</span>
    </li>
  </ol>`} />

### Horizontal layout

`.horizontal` switches a list from column to row layout. Adjacent items share a single border edge, and outer corners remain rounded while inner corners are squared off.

Responsive variants use [container queries]([[docsref:/layout/breakpoints#container-queries]]) — each `.{breakpoint}:horizontal` class activates at or above the specified container width. Wrap the list in `.contains-inline` to establish the container context. Resize the example below to see the breakpoint transitions.

<Callout type="warning">
  `.horizontal` cannot be combined with `.flush` — the flush variant removes inline borders that separate items in the horizontal layout.
</Callout>

<ResizableExample code={[`<div class="contains-inline">`, 
  ...getData('breakpoints').filter($breakpoint => !['xl:', '2xl:']
    .includes($breakpoint.abbr)).map((breakpoint) => `  <ul class="list ${breakpoint.abbr}horizontal mb-md">
      <li class="list-item">An item</li>
      <li class="list-item">A second item</li>
      <li class="list-item">A third item</li>
    </ul>`), 
  `</div>`]} />

Apply `.flex-fill` or `.flex-grow-1` to list items to stretch them across the full list width:

- `.flex-fill` — items share the available width equally, regardless of content length
- `.flex-grow-1` — items grow from their natural content width; items with longer content end up wider

<Example code={`<ul class="list horizontal mb-md">
    <li class="list-item flex-fill">An item</li>
    <li class="list-item flex-fill">Second item</li>
    <li class="list-item flex-fill">And the longer third item</li>
  </ul>
  <ul class="list horizontal">
    <li class="list-item flex-grow-1">An item</li>
    <li class="list-item flex-grow-1">Second item</li>
    <li class="list-item flex-grow-1">And the longer third item</li>
  </ul>`} />

## Component combinations

List items hold other components and custom markup: badges, headings and text, and form controls.

### Items with badges

Add a [badge]([[docsref:/components/badge]]) to a list item to show a count or a status. The flex utilities on the item push the badge to the end and center it vertically.

<Example code={`<ul class="list">
    <li class="list-item d-flex justify-content-between align-items-center">
      A list item
      <span class="badge primary">14</span>
    </li>
    <li class="list-item d-flex justify-content-between align-items-center">
      A second list item
      <span class="badge primary">2</span>
    </li>
    <li class="list-item d-flex justify-content-between align-items-center">
      A third list item
      <span class="badge primary">1</span>
    </li>
  </ul>`} />

### Rich content

A list item accepts nearly any markup: headings, paragraphs, metadata. [Flexbox utilities]([[docsref:/utilities/flex]]) lay the content out inside the item.

<Example code={`<div class="list">
    <a href="#" class="list-item list-action active" aria-current="true">
      <div class="d-flex w-100 justify-content-between">
        <h4 class="font-lg mb-2xs">List item heading</h4>
        <small>3 days ago</small>
      </div>
      <p class="mb-2xs">Some placeholder content in a paragraph.</p>
      <small>And some small print.</small>
    </a>
    <a href="#" class="list-item list-action">
      <div class="d-flex w-100 justify-content-between">
        <h4 class="font-lg mb-2xs">List item heading</h4>
        <small class="fg-subtle">3 days ago</small>
      </div>
      <p class="mb-2xs">Some placeholder content in a paragraph.</p>
      <small class="fg-subtle">And some muted small print.</small>
    </a>
    <a href="#" class="list-item list-action">
      <div class="d-flex w-100 justify-content-between">
        <h4 class="font-lg mb-2xs">List item heading</h4>
        <small class="fg-subtle">3 days ago</small>
      </div>
      <p class="mb-2xs">Some placeholder content in a paragraph.</p>
      <small class="fg-subtle">And some muted small print.</small>
    </a>
  </div>`} />

### Form controls

Place checkboxes or radios inside list items for a selectable list. Each item holds a `.check-input` and its `<label>`.

<Callout type="info">
  Every control needs an accessible name. Without a visible label, add an `aria-label` attribute to the input.
</Callout>

<Example code={`<ul class="list">
    <li class="list-item">
      <input class="check-input me-xs" type="checkbox" value="" id="firstCheckbox">
      <label for="firstCheckbox">First checkbox</label>
    </li>
    <li class="list-item">
      <input class="check-input me-xs" type="checkbox" value="" id="secondCheckbox">
      <label for="secondCheckbox">Second checkbox</label>
    </li>
    <li class="list-item">
      <input class="check-input me-xs" type="checkbox" value="" id="thirdCheckbox">
      <label for="thirdCheckbox">Third checkbox</label>
    </li>
  </ul>`} />

#### Stretched labels

Apply the `.stretched-link` class to the `<label>` to extend its clickable area over the entire list item, which gives a larger target on touch devices.

<Example code={`<ul class="list">
    <li class="list-item">
      <input class="check-input me-xs" type="checkbox" value="" id="firstCheckboxStretched">
      <label class="stretched-link" for="firstCheckboxStretched">First checkbox</label>
    </li>
    <li class="list-item">
      <input class="check-input me-xs" type="checkbox" value="" id="secondCheckboxStretched">
      <label class="stretched-link" for="secondCheckboxStretched">Second checkbox</label>
    </li>
    <li class="list-item">
      <input class="check-input me-xs" type="checkbox" value="" id="thirdCheckboxStretched">
      <label class="stretched-link" for="thirdCheckboxStretched">Third checkbox</label>
    </li>
  </ul>`} />

## Context variants

Context classes give a list, or single items, the colors of a context. Apply `.context.{name}` to a `.list-item` to mark its state, importance or category.

<Example code={[
    `<ul class="list">`,
    ...getData('context-colors').map((contextColor) => `  <li class="list-item context ${contextColor.name}">A simple ${contextColor.name} list item</li>`),
    `</ul>`
  ]} />

### Interactive items

Combine a context class with `.list-action` for actionable items in a context color: the hover, pressed and active states use the colors of the item's context. Apply `.active` to mark the selected item.

<Example code={[
    `<div class="list list-action">`,
    ...getData('context-colors').map((contextColor) => `  <a href="#" class="list-item context ${contextColor.name}">A simple ${contextColor.name} list action</a>`),
    `</div>`
  ]} />

<Callout name="warning-color-assistive-technologies" />

A context class on the `.list` element colors the whole list, and the `.solid`, `.smooth` and `.outline` classes next to it select how: each sets the background, border and text colors of the context in its own style.

## JavaScript API

Lists have no plugin of their own. The [Tab plugin]([[docsref:/components/tab]]) turns a list of actionable items into the navigation of tabbed content. Chassis JS ships as an ES module — import the `Tab` class:

```js
import { Tab } from '@chassis-ui/css'
```

### Tabbed navigation

Each list item is a tab that shows its `.tab-pane` and takes the `.active` class, so the list keeps its appearance while it controls which pane is visible.

### Triggers

The data-attribute API needs no JavaScript on the page beyond the plugin. Add `data-cx-toggle="tab"` to each list item, and point its `href` (or `data-cx-target` on a button) at the `id` of a `.tab-pane`.

```html
<div role="tabpanel">
  <!-- List -->
  <div class="list" id="myList" role="tablist">
    <a class="list-item list-action active" data-cx-toggle="tab" href="#home" role="tab">Home</a>
    <a class="list-item list-action" data-cx-toggle="tab" href="#profile" role="tab">Profile</a>
    <a class="list-item list-action" data-cx-toggle="tab" href="#messages" role="tab">Messages</a>
    <a class="list-item list-action" data-cx-toggle="tab" href="#settings" role="tab">Settings</a>
  </div>

  <!-- Tab panes -->
  <div class="tab-content">
    <div class="tab-pane active" id="home" role="tabpanel">...</div>
    <div class="tab-pane" id="profile" role="tabpanel">...</div>
    <div class="tab-pane" id="messages" role="tabpanel">...</div>
    <div class="tab-pane" id="settings" role="tabpanel">...</div>
  </div>
</div>
```

The [Tab documentation]([[docsref:/components/tab]]) covers programmatic initialization, methods and events.
