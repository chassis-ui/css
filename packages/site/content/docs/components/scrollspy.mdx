## Introduction

Scrollspy updates the active link of a navigation as the content scrolls. Each link points to a section by its `id`, and the plugin adds `.active` to the link whose section is in view and removes it from the others.

### How it works

The plugin watches the sections with the [Intersection Observer API](https://developer.mozilla.org/en-US/docs/Web/API/Intersection_Observer_API) instead of listening to scroll events. It pairs every link inside the target with the element its `href` hash names, and observes that element within the scrollable container.

The active state also reaches the parents of a link. In nested `.nav` elements, the `.nav-link` before the nested nav becomes active with it, and a `.menu-item` activates the toggle of its menu.

<Callout name="info-prefersreducedmotion" />

## Basic structure

Scrollspy needs a scrollable container and a navigation whose links point to elements inside it:

- The scrollable container is the `<body>` element, or an element with a set `height` and `overflow-y: scroll`.
- Add `data-cx-spy="scroll"` to the container, and `data-cx-target` with a selector for the element that holds the links.
- Add `tabindex="0"` to a container other than `<body>` when it holds no focusable element, so keyboard users can scroll it.
- Each link needs an `href` with the `id` of an element inside the container. Links that are disabled or that point to a missing or hidden element are ignored.

## Navigation patterns

Scrollspy follows any set of anchors, not only a navbar: nested navs, lists, and plain links are tracked the same way.

## Non-visible elements

Target elements that are not visible are ignored, and their links never receive `.active`. An instance initialized in a non-visible wrapper ignores all of its targets. Call the `refresh` method once the wrapper becomes visible, for example when a tab pane with a scrollspy container is shown:

```js
import { ScrollSpy } from '@chassis-ui/css'

document.querySelectorAll('#nav-tab>[data-cx-toggle="tab"]').forEach(el => {
  el.addEventListener('shown.cx.tab', () => {
    const target = el.getAttribute('data-cx-target')
    const scrollElem = document.querySelector(`${target} [data-cx-spy="scroll"]`)
    ScrollSpy.getOrCreateInstance(scrollElem).refresh()
  })
})
```

## Accessibility

The plugin changes only the `.active` class of the links and sets no ARIA attribute, so the active section is conveyed visually only. To expose it to assistive technologies, set `aria-current="true"` on the link in an `activate.cx.scrollspy` listener, where the link is `event.relatedTarget`, and remove the attribute from the link that was active before.

The links stay native anchors: they are focusable and activate with <kbd>Enter</kbd> whether or not the plugin runs. A scrollable container without a focusable element needs `tabindex="0"`, otherwise keyboard users cannot focus it to scroll its content.

## JavaScript API

The ScrollSpy plugin observes the sections of a scrollable container and updates the links of its target. Import the `ScrollSpy` class from the Chassis module:

```js
import { ScrollSpy } from '@chassis-ui/css'
```

### Triggers

The data-attribute API sets up scrollspy without any JavaScript on the page beyond the bundled plugin. Add `data-cx-spy="scroll"` to the scrollable element, typically the `<body>` or a scrollable container, and `data-cx-target` with a selector for the parent element of the navigation:

```html
<body data-cx-spy="scroll" data-cx-target="#navbar-example">
  ...
  <div id="navbar-example">
    <ul class="nav nav-tabs">
      ...
    </ul>
  </div>
  ...
</body>
```

### Initialization

For content added after the page has loaded, or to pass options as an object, instantiate the scrollable element with the `ScrollSpy` class:

```js
const scrollSpy = new ScrollSpy(document.body, {
  target: '#navbar-example'
})
```

### Options

<JsDataAttributes />

<CxTable>
| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `rootMargin` | string | `0px 0px -25%` | [`rootMargin`](https://developer.mozilla.org/en-US/docs/Web/API/IntersectionObserver/rootMargin) of the `IntersectionObserver` that detects the visible sections. |
| `smoothScroll` | boolean | `false` | Scrolls smoothly to a section when its link is clicked. |
| `target` | string, DOM element | `null` | Element that holds the links to update. Falls back to the `<body>` element when it is not set. |
| `threshold` | array | `[0.1, 0.5, 1]` | [`threshold`](https://developer.mozilla.org/en-US/docs/Web/API/IntersectionObserver/IntersectionObserver#threshold) of the `IntersectionObserver`. A comma-separated string, such as `"0.1,0.5,1"`, is also accepted. |
</CxTable>

### Methods

The plugin exposes two instance methods and two static lookup methods for programmatic control:

<CxTable>
| Method | Description |
| --- | --- |
| `dispose` | Destroys the instance and removes stored data from the element. |
| `getInstance` | *Static* — returns the existing instance bound to a DOM element, or `null`. Example: `ScrollSpy.getInstance(element)` |
| `getOrCreateInstance` | *Static* — returns the existing instance or creates one. Example: `ScrollSpy.getOrCreateInstance(element)` |
| `refresh` | Collects the links and their sections again. Call it after adding or removing links or sections in the DOM, or after a hidden container becomes visible. |
</CxTable>

A call to `refresh` on every instance picks up content that was added to the page:

```js
const dataSpyList = document.querySelectorAll('[data-cx-spy="scroll"]')
dataSpyList.forEach(dataSpyEl => {
  ScrollSpy.getInstance(dataSpyEl).refresh()
})
```

### Events

The plugin fires one event on the scrollable element, for integrating the active link with other parts of the page.

<CxTable>
| Event | Description |
| --- | --- |
| `activate.cx.scrollspy` | Fired on the scroll element whenever a link becomes active. `event.relatedTarget` is that link. |
</CxTable>

```js
const firstScrollSpyEl = document.querySelector('[data-cx-spy="scroll"]')
firstScrollSpyEl.addEventListener('activate.cx.scrollspy', event => {
  event.relatedTarget // newly activated link
})
```
