## Introduction

Pagination links the pages of multi-page content, such as search results or a list of posts. The component is a list of page links in a flex row, where every link has a minimum width and height, and state classes mark the current page and the links that are unavailable.

## Basic structure

Wrap a `<ul>` with the `.pagination` class in a `<nav>` element, and give each `<li>` the `.pagination-item` class and each link the `.pagination-link` class. The `<nav>` exposes the component as a navigation landmark: label it with `aria-label`, and use distinct labels, such as `aria-label="Search results pages"`, when a page has more than one. Links that hold only an icon need an `aria-label` of their own.

<Example code={`<nav aria-label="Page navigation example">
    <ul class="pagination">
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Previous">
          <Icon name="chevron-left-solid" class="directional-icon" />
        </a>
      </li>
      <li class="pagination-item"><a class="pagination-link" href="#">1</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">2</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">3</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">4</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">5</a></li>
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Next">
          <Icon name="chevron-right-solid" class="directional-icon" />
        </a>
      </li>
    </ul>
  </nav>`} />

## Variants

Modifier classes on `.pagination` add borders to the page links, either as separate boxes or as one connected group.

### Bordered

Add `.bordered` next to `.pagination` to give each page link a border and to separate the links with a gap.

<Example code={`<nav aria-label="Page navigation example">
    <ul class="pagination bordered">
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Previous">
          <Icon name="chevron-left-solid" class="directional-icon" />
        </a>
      </li>
      <li class="pagination-item"><a class="pagination-link" href="#">1</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">2</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">3</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">4</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">5</a></li>
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Next">
          <Icon name="chevron-right-solid" class="directional-icon" />
        </a>
      </li>
    </ul>
  </nav>`} />

### Grouped

Add `.grouped` to join the bordered page links into a single unit: adjacent borders overlap, and only the outer corners of the first and last links are rounded.

<Example code={`<nav aria-label="Page navigation example">
    <ul class="pagination grouped">
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Previous">
          <Icon name="chevron-left-solid" class="directional-icon" />
        </a>
      </li>
      <li class="pagination-item"><a class="pagination-link" href="#">1</a></li>

## Active and disabled

The `.active` class highlights the current page and the `.disabled` class marks a link that is unavailable. Both work on the `.pagination-item` or directly on the `.pagination-link`. Mark the current page with `aria-current="page"` as well, since the class alone is not announced.

The `.disabled` class only sets `pointer-events: none`, which does not stop keyboard activation. Replace a disabled link with a `<span>`, as the previous control of the example does, or add `tabindex="-1"` and `aria-disabled="true"` to the `<a>` element.

<Example code={`<nav aria-label="...">
    <ul class="pagination">
      <li class="pagination-item disabled">
        <span class="pagination-link">
          <Icon name="chevron-left-solid" class="directional-icon" />
        </span>
      </li>
      <li class="pagination-item active"><a class="pagination-link" href="#">1</a></li>
      <li class="pagination-item" aria-current="page">
        <a class="pagination-link" href="#">2</a>
      </li>
      <li class="pagination-item"><a class="pagination-link" href="#">3</a></li>
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Next">
          <Icon name="chevron-right-solid" class="directional-icon" />
        </a>
      </li>
    </ul>
  </nav>`} />

## Sizing

Pagination comes in three sizes. The `.lg` and `.sm` classes next to `.pagination` change the minimum size, the radius and the font size of the page links; the medium size needs no class.

<Example code={`<nav aria-label="...">
    <ul class="pagination lg">
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Previous">

        </a>

## Alignment

The `.pagination` element is a flex container, so the [justify-content utilities]([[docsref:/utilities/flex#justify-content]]) align its page links. The `.justify-content-center` class centers them.

<Example code={`<nav aria-label="Centered pagination">
    <ul class="pagination justify-content-center">
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Previous">
          <Icon name="chevron-left-solid" class="directional-icon" />
        </a>
      </li>
      <li class="pagination-item"><a class="pagination-link" href="#">1</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">2</a></li>
      <li class="pagination-item"><a class="pagination-link" href="#">3</a></li>
      <li class="pagination-item">
        <a class="pagination-link" href="#" aria-label="Next">
          <Icon name="chevron-right-solid" class="directional-icon" />
        </a>
      </li>
    </ul>
  </nav>`} />

The `.justify-content-end` class aligns them to the end of the row.

<Example code={`<nav aria-label="Right-aligned pagination">
