## Introduction

The `.form-input` element acts as a flex container that positions `.input-adorn` elements before or after a `.ghost-input` input. The ghost input fills the available space while adornments shrink to their content.

See the [Form Input]([[docsref:/forms/form-input]]) documentation for more on the `.form-input` and `.ghost-input` classes.

## Basic structure

Wrap a `.ghost-input` and one or more `.input-adorn` elements in a `.form-input` element. The position of `.input-adorn` within the wrapper controls whether it appears at the start or end of the field.

### Leading

Place `.input-adorn` as the first child of `.form-input` to position it at the leading edge.

<Example code={`<div class="form-input">
    <span class="input-adorn">
      <Icon name="search-outline" />
    </span>
    <input type="text" class="ghost-input" aria-label="Search" placeholder="Search...">
  </div>`} />

### Trailing

Place `.input-adorn` as the last child to position it at the trailing edge.

<Example code={`<div class="form-input">
    <input type="email" class="ghost-input" aria-label="Email address" placeholder="you@example.com">
    <span class="input-adorn">
      <Icon name="envelope-outline" />
    </span>
  </div>`} />

## Text adornments

Use `.input-adorn` for currency symbols, units, domain suffixes, and other text-based decorations. When the adornment is essential to understanding what the field expects, include it in the input's accessible name via `aria-label`.

<Example class="vstack gap-xs" code={`<div class="form-input">
    <span class="input-adorn">$</span>
    <input type="text" class="ghost-input" aria-label="Amount in dollars" placeholder="0.00">
  </div>
  <div class="form-input">
    <input type="text" class="ghost-input" aria-label="Amount" placeholder="Amount">
    <span class="input-adorn">USD</span>
  </div>
  <div class="form-input">
    <span class="input-adorn">https://</span>
    <input type="text" class="ghost-input" aria-label="Website URL" placeholder="example.com">
  </div>
  <div class="form-input">
    <input type="text" class="ghost-input" aria-label="Username" placeholder="username">
    <span class="input-adorn">@example.com</span>
  </div>`} />

### Combined

Combine a leading and a trailing adornment for fields that need positional context on both edges.

<Example code={`<div class="form-input">
    <span class="input-adorn">
      <Icon name="envelope-outline" />
    </span>
    <input type="text" class="ghost-input" aria-label="Username" placeholder="Username">
    <span class="input-adorn">@example.com</span>
  </div>`} />

## Layout

The `.form-input` wrapper is a flex container, so an adorned input combines with labels, help text, and form fields like any other input.

### Label and help

Add a label outside the `.form-input` wrapper and associate help text with `aria-describedby`.

<Example code={`<label for="searchAssist" class="form-label">Search</label>
  <div class="form-input">
    <span class="input-adorn">
      <Icon name="search-outline" />
    </span>
    <input type="text" class="ghost-input" id="searchAssist" aria-describedby="searchAssistHelp" placeholder="Search...">
  </div>
  <div class="form-help" id="searchAssistHelp">Search across all pages and posts.</div>`} />

### In a form field

Wrap `.form-input` in `.form-field` to integrate with labels, help text, and validation feedback.

<Example code={`<div class="form-field">
    <label for="helpField" class="form-label">Search</label>
    <div class="form-input">
      <span class="input-adorn">
        <Icon name="search-outline" />
      </span>
      <input type="text" class="ghost-input" id="helpField" aria-describedby="helpFieldHelp" placeholder="Search...">
    </div>
    <div class="form-help" id="helpFieldHelp">Search across all pages and posts.</div>
  </div>`} />

  </div>`} />

## Actionable adornments

Use `.input-adorn` on a `<button>` element for actions such as showing a password, clearing the input, or triggering a search. A button adornment drops the padding, minimum size, background, and border of a button, so it takes no more room than its icon.

<Example class="vstack gap-xs" code={`<div class="form-input">
    <input type="password" autocomplete="current-password" class="ghost-input" aria-label="Password" placeholder="Password">
    <button type="button" class="button icon-only input-adorn" aria-label="Show password">
      <Icon name="eye-outline" />
    </button>
  </div>
  <div class="form-input">
    <input type="password" autocomplete="current-password" class="ghost-input" aria-label="Password" placeholder="Password">
    <a href="#" class="input-adorn">Forgot password?</a>
  </div>`} />

## Accessibility

Input adornment introduces visual elements — icons, text, and buttons — that sit alongside the input but are separate from it in the DOM. Assistive technologies need the meaning of each adornment in the markup.

### Decorative icons

Icon adornments that provide a visual hint rather than essential information should have `aria-hidden="true"` on the `<svg>` element. The input's accessible name — provided by a `<label>` or `aria-label` — carries the full meaning independently.

```html
<label for="searchInput" class="form-label">Search</label>
<div class="form-input">
  <span class="input-adorn">
    <svg class="icon" aria-hidden="true"><use href="#search-outline" /></svg>
  </span>
  <input type="text" class="ghost-input" id="searchInput" />
</div>
```

### Adornment text

Text adornments like `$`, `USD`, or `@example.com` are not part of the accessible name of the input. When the adornment is essential to understanding what the field expects, include it in the input's accessible name via `aria-label`.

```html
<div class="form-input">
  <span class="input-adorn">$</span>
  <input type="text" class="ghost-input" aria-label="Amount in dollars" placeholder="0.00" />
</div>
```

### Icon-only buttons

Button adornments that contain only an icon have no text for screen readers to announce. Always add `aria-label` describing the action.

```html
<div class="form-input">
  <input type="password" autocomplete="current-password" class="ghost-input" aria-label="Password" placeholder="Password">
  <button type="button" class="button icon-only input-adorn" aria-label="Show password">
    <svg class="icon" aria-hidden="true"><use href="#eye-outline" /></svg>
  </button>
</div>
```

For more detailed accessibility guidance, see the [accessibility section of the forms overview]([[docsref:/forms/overview/#accessibility]]).
