import { formatHex, parse } from 'culori'
import { sassVars } from '@libs/sass'
export const _now = new Date()
export const _pad = n => String(n).padStart(2, '0')
export const _date = `${_now.getFullYear()}-${_pad(_now.getMonth() + 1)}-${_pad(_now.getDate())}`
export const _time = `${_pad(_now.getHours())}:${_pad(_now.getMinutes())}`

<Callout type="warning" class="-my-xs">
  The examples on this page leave out labels to keep the markup on the class they demonstrate. In production, give every input a `<label>` or an `aria-label`, so the control has an accessible name.
</Callout>

## Introduction

The `.form-input` class gives `<input>`, `<select>`, and `<textarea>` elements the same typography, padding, border, colors, and focus ring. Size modifiers, the native `disabled` and `readonly` attributes, and the plaintext and ghost variants build on that one class.

## Basic structure

Add `.form-input` to an `<input>`, a `<select>`, or a `<textarea>` element. Inputs are block-level and take the full width of their container.

<Example class="vstack gap-xs" code={`<input class="form-input" type="text" placeholder="Example text input">
  <select class="form-input">
    <option value="">Example select</option>
    <option value="option1">Option one</option>
    <option value="option2">Option two</option>
  </select>
  <textarea class="form-input" placeholder="Example textarea"></textarea>`} />

<Callout type="info">
  The caret of a select is a background image that follows the disabled state and dark mode. Change the icon with [Chassis Tokens]([[docsref:/core-concepts/design-tokens]]), or override the [custom properties](#custom-properties) at runtime.
</Callout>

## Select

A `<select>` with `.form-input` shows a caret at its inline end. The caret is removed for the list forms of a select: add the `multiple` attribute to allow several selections.

<Example class="vstack gap-xs" code={`<select class="form-input" multiple>
    <option value="option1">Option one</option>
    <option value="option2">Option two</option>
    <option value="option3">Option three</option>
  </select>`} />

Set the `size` attribute to show a fixed number of options as a list.

<Example class="vstack gap-xs" code={`<select class="form-input" size="3">
    <option value="option1">Option one</option>
    <option value="option2">Option two</option>
    <option value="option3">Option three</option>
  </select>`} />

## Textarea

A `<textarea>` with `.form-input` is at least as tall as an input. Set the `rows` attribute for a taller one.

<Example class="vstack gap-xs" code={`<textarea class="form-input" placeholder="Example textarea with rows attribute" rows="4"></textarea>`} />

## Sizing

Add `.sm` or `.lg` to a `.form-input` to change its height, padding, and font size. The sizes match the sizes of buttons and the other form components.

<Example class="vstack gap-xs" code={`<input class="form-input lg" type="text" placeholder="Large input">
<input class="form-input" type="text" placeholder="Default input">
<input class="form-input sm" type="text" placeholder="Small input">`} />

## States

Form inputs style the native `disabled` and `readonly` states, so no state class is needed.

### Disabled inputs

Add the `disabled` attribute to an input to make it unavailable. The input takes the disabled form colors, and the browser removes it from the tab order and from form submission.

<Example class="vstack gap-xs" code={`<input class="form-input" type="text" placeholder="Disabled input" disabled>
  <input class="form-input" type="text" value="Disabled input with value" disabled>
  <select class="form-input" disabled>
    <option value="">Disabled select</option>
    <option value="option1">Option one</option>
    <option value="option2">Option two</option>
</select>`} />

### Readonly inputs

Add the `readonly` attribute to keep the value of an input from changing while it stays selectable. Unlike a disabled input, a read-only input remains focusable and is submitted with the form.

<Example class="vstack gap-xs" code={`<input class="form-input" type="text" value="Readonly input" readonly>
<input class="form-input" type="text" value="Readonly disabled input" readonly disabled>`} />

## Plaintext inputs

Combine `readonly` with the `.plaintext` class to show a value as plain text: the class removes the background and the border and keeps the padding, so the text aligns with the inputs next to it.

<Example class="vstack gap-xs" code={`<input class="form-input plaintext" readonly type="text" value="email@example.com">
  <input class="form-input" type="password" autocomplete="current-password" placeholder="Password">`} />

<Example class="vstack gap-xs" code={`<form class="d-flex flex-wrap gap-md">
    <div>
      <input class="form-input plaintext" readonly type="text" value="email@example.com">
    </div>
    <div>
      <input class="form-input" type="password" autocomplete="current-password" placeholder="Password">
    </div>
    <div>
      <button type="submit" class="button primary">Submit</button>
    </div>
  </form>`} />

## Input types

`.form-input` applies to every text-like `type` of `<input>`, such as `text`, `password`, `email`, and `number`. The file, color, and date types have rules of their own.

### File input

On an `<input type="file">`, `.form-input` styles the file selector button with the colors of an input addon. Choosing files stays the browser's own dialog.

<Example class="vstack gap-xs" code={`<input class="form-input" type="file">
  <input class="form-input" type="file" multiple>
  <input class="form-input" type="file" disabled>`} />

### Color input

On an `<input type="color">`, `.form-input` sizes the swatch to the height of an input and rounds it with the radius of the form controls.

<Example code={`<input class="form-input" type="color" value="${formatHex(parse(sassVars('color')['primary']))}">`} />

[Display]([[docsref:/utilities/display]]) and [sizing]([[docsref:/utilities/sizing]]) utilities set the width of a color input and place several on one line.

<Example code={`<input class="form-input d-inline-flex w-25 me-md" type="color" value="${formatHex(parse(sassVars('color')['primary']))}">
<input class="form-input d-inline-flex w-25" type="color" value="${formatHex(parse(sassVars('color')['secondary']))}">`} />

### Date and time

The `date`, `time`, and `datetime-local` types keep the picker of the browser, and `.form-input` gives them the height of the other inputs.

<Example code={`<input class="form-input" type="datetime-local" value="${_date}T${_time}">
<input class="form-input" type="date" value="${_date}">
<input class="form-input" type="time" value="${_time}">`} />

### Datalists

Connect a text input to a `<datalist>` element with the `list` attribute to suggest values while the user types. The input still accepts any text.

<Example code={`<input type="text" class="form-input" list="datalistOptions" placeholder="Type to search...">
  <datalist id="datalistOptions">
    <option value="Option one"></option>
    <option value="Option two"></option>
    <option value="Option three"></option>
  </datalist>`} />

## Ghost inputs

The `.ghost-input` class removes the background, the border, and the padding of an input and leaves the styling to a wrapper, for custom controls that hold an input next to other content.

`.ghost-input` also removes the focus outline of the input, so the wrapper has to show the focus, for example with `:focus-within`.

<Example class="vstack gap-xs" code={`<input class="ghost-input" type="search" placeholder="Search items">`} />

### Form input wrapper

A `.form-input` element around a ghost input is that wrapper: it draws the border, the padding, and the size variants, shows the focus ring while the input inside has focus, and takes the disabled colors when the input is disabled.

<Example class="vstack gap-xs" code={`<div class="form-input">
    <input class="ghost-input" type="search" placeholder="Search items">
  </div>
  <div class="form-input">
    <input class="ghost-input" type="search" placeholder="Search items" disabled>
  </div>
  <div class="form-input lg">
    <input class="ghost-input" type="search" placeholder="Search items">
  </div>
  <div class="form-input sm">
    <input class="ghost-input" type="search" placeholder="Search items">
  </div>`} />
