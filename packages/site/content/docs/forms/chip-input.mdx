## Introduction

A chip input is a text field that holds several values: each typed entry becomes a removable [chip]([[docsref:/components/chip]]). `.chip-input` is the unstyled container of the chips and of a `.ghost-input`; add `.form-input` next to it for the appearance of a text field.

## Basic structure

Add `data-cx-chips` to the container to enable the plugin. Typing a value and pressing <kbd>Enter</kbd> or <kbd>,</kbd> creates a chip; the close button of a chip, or <kbd>Backspace</kbd> on a focused chip, removes it.

The value of `data-cx-chips` sets the classes of every chip the input creates — `data-cx-chips="primary smooth"` produces chips with the `.primary` and `.smooth` classes. Omit the value or use `default` for the default chip appearance.

<Example code={`<div class="form-input chip-input" data-cx-chips>
    <span class="chip" data-cx-chip-value="JavaScript">JavaScript</span>
    <span class="chip" data-cx-chip-value="TypeScript">TypeScript</span>
    <input type="text" class="ghost-input" placeholder="Add skill…" />
  </div>`} />

## Chip styles

Pass any combination of chip modifier classes as the `data-cx-chips` value to set the appearance of the chips the input creates. Give the chips that are already in the markup the same classes: the plugin applies the value only to the chips it creates.

<Example class="vstack gap-md" code={`<div class="form-input chip-input" data-cx-chips="primary">
    <span class="chip" data-cx-chip-value="Approved">Approved</span>
    <span class="chip" data-cx-chip-value="Verified">Verified</span>
    <input type="text" class="ghost-input" placeholder="Add status…" />
  </div>
  <div class="form-input chip-input" data-cx-chips="danger smooth">
    <span class="chip" data-cx-chip-value="Bug">Bug</span>
    <span class="chip" data-cx-chip-value="Critical">Critical</span>
    <input type="text" class="ghost-input" placeholder="Add issue…" />
  </div>
  <div class="form-input chip-input" data-cx-chips="default outline">
    <span class="chip" data-cx-chip-value="Draft">Draft</span>
    <span class="chip" data-cx-chip-value="Review">Review</span>
    <input type="text" class="ghost-input" placeholder="Add label…" />
  </div>`} />

## Mixed chip styles

Chips in the markup can carry classes that differ from the `data-cx-chips` value, and keep them. Only the chips added at runtime receive the classes of `data-cx-chips`.

<Example code={`<div class="form-input chip-input" data-cx-chips="primary smooth">
    <span class="chip default" data-cx-chip-value="Low">Low</span>
    <span class="chip warning smooth" data-cx-chip-value="Medium">Medium</span>
    <span class="chip danger smooth" data-cx-chip-value="High">High</span>
    <input type="text" class="ghost-input" placeholder="Add priority…" />
  </div>`} />

## Empty state

A chip input can start with the `.ghost-input` alone, without any `.chip` element: the plugin creates the chips as the user types.

<Example code={`<div class="form-input chip-input" data-cx-chips="primary smooth">
    <input type="text" class="ghost-input" placeholder="Type and press Enter…" />
  </div>`} />

## With form field

Wrap the chip input in a [form field]([[docsref:/forms/form-field]]) to pair it with a label, help text, and validation feedback.

<Example code={`<div class="form-field">
    <label class="form-label" for="skillsInput">Skills</label>
    <div class="form-input chip-input" data-cx-chips="primary smooth">
      <span class="chip" data-cx-chip-value="React">React</span>
      <span class="chip" data-cx-chip-value="CSS">CSS</span>
      <input type="text" class="ghost-input" placeholder="Add skill…" id="skillsInput" />
    </div>
    <div class="form-help">Press <kbd>Enter</kbd> or <kbd>,</kbd> to add a skill.</div>
  </div>`} />

<Callout type="info">
  Point the label's `for` attribute at the ghost input's `id`, not the container's `id`. The container does not need its own `id`.
</Callout>

## Disabled

Apply the `disabled` attribute to the ghost input to prevent new chips from being added. The existing chips are dimmed and ignore pointer events.

<Example code={`<div class="form-input chip-input" data-cx-chips="primary smooth">
    <span class="chip" data-cx-chip-value="React">React</span>
    <span class="chip" data-cx-chip-value="CSS">CSS</span>
    <input type="text" class="ghost-input" placeholder="Disabled…" disabled />
  </div>`} />

## Floating labels

A chip input works inside a [floating label container]([[docsref:/forms/floating-labels]]) like a text input.

<Example code={`<div class="form-floating mb-md">
    <label for="floatingInput">Add chips</label>
    <div class="chip-input form-input" data-cx-chips="primary smooth">
      <span class="chip" data-cx-chip-value="A Chip">A Chip</span>
      <span class="chip" data-cx-chip-value="Another Chip">Another Chip</span>
      <input type="text" class="ghost-input" id="floatingInput" />
    </div>
  </div>`} />

## Accessibility

The plugin makes every chip focusable with `tabindex="0"` and keeps `aria-selected` on it in sync with the selection. The close button it adds to a chip has `aria-label="Remove"` and stays out of the tab order, since the keyboard removes a chip from the chip itself. The container gets no role or name from the plugin: label the `.ghost-input`, as in [With form field](#with-form-field).

### Keys in the input

While the `.ghost-input` has the focus, the keys create chips and move the focus to the existing ones.

<CxTable>
| Key | Action |
| --- | --- |
| <kbd>Enter</kbd> | Create a chip from the current input value. |
| <kbd>,</kbd> (or separator) | Create a chip from the current input value. |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> | When the input is empty, select and focus the last chip. |
| <kbd>←</kbd> | When the cursor is at the start, select and focus the last chip. |
| <kbd>Shift</kbd>+<kbd>←</kbd> | When the cursor is at the start, add the last chip to the selection and focus it. |
| <kbd>Escape</kbd> | Clear selection, clear the input value, and blur. |
</CxTable>

### Keys on a chip

While a chip has the focus, the keys move between the chips, extend the selection and remove chips.

<CxTable>
| Key | Action |
| --- | --- |
| <kbd>Backspace</kbd> / <kbd>Delete</kbd> | Remove all selected chips, or the focused chip when none is selected, and focus the next closest chip or the input. |
| <kbd>←</kbd> | Move to the previous chip. |
| <kbd>→</kbd> | Move to the next chip, or to the input if already at the last chip. |
| <kbd>Shift</kbd>+<kbd>←</kbd> / <kbd>Shift</kbd>+<kbd>→</kbd> | Extend the selection in that direction. |
| <kbd>Home</kbd> | Move to the first chip. |
| <kbd>End</kbd> | Move focus to the input. |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+<kbd>A</kbd> | Select all chips. |
| <kbd>Escape</kbd> | Clear selection and return focus to the input. |
</CxTable>

### Mouse and pointer

A click selects one chip, and the modifier keys extend the selection to several.

<CxTable>
| Action | Effect |
| --- | --- |
| Click chip | Select that chip (clears any previous selection). |
| <kbd>Cmd</kbd>/<kbd>Ctrl</kbd>+click | Toggle the chip in or out of the current selection. |
| <kbd>Shift</kbd>+click | Range-select from the anchor chip to the clicked chip. |
| Click close button | Remove the chip immediately. |
| Click container background | Clear selection and focus the input. |
</CxTable>

## JavaScript API

The ChipInput plugin creates and removes chips, tracks their selection, and fires an event for each change. Chassis JS ships as an ES module — import the `ChipInput` class:

```js
import { ChipInput } from '@chassis-ui/css'
```

### Triggers

A container with `data-cx-chips` is initialized when the page loads. The value of the attribute sets the classes of the created chips.

```html
<div class="form-input chip-input" data-cx-chips="primary smooth">
  <input type="text" class="ghost-input" placeholder="Add tags…" />
</div>
```

Further `data-cx-*` attributes on the container set the [options](#options) of the plugin:

<CxTable>
| Attribute | Description |
| --- | --- |
| `data-cx-chips` | Initializes chip input. The value sets the chip style classes (`"primary smooth"`, `"default"`, etc.). |
| `data-cx-separator` | Character that creates a new chip when typed. Default is `","`. Set to `null` to disable. |
| `data-cx-allow-duplicates` | Set to `"true"` to allow the same value to be added more than once. |
| `data-cx-max-chips` | Maximum number of chips allowed. Omit for no limit. |
| `data-cx-create-on-blur` | Set to `"false"` to prevent chip creation when the input loses focus. |
</CxTable>

Typed or pasted text that contains the separator is split at it: every part before the last separator becomes a chip, and the rest stays in the input.

### Initialization

Create an instance with the `ChipInput` class for a container added after the page has loaded, or to pass the options as an object:

```js
const el = document.querySelector('.form-input.chip-input')
const chipInput = new ChipInput(el, {
  separator: ',',
  maxChips: 5,
  chipClass: 'primary smooth'
})
```

### Methods

The plugin exposes instance methods to add, remove and select chips and to read their values:

<CxTable>
| Method | Description |
| --- | --- |
| `add(value)` | Creates a chip with the given value. Returns the chip element, or `null` if the value was rejected (empty, duplicate, or max reached). |
| `remove(chipOrValue)` | Removes a chip by element reference or value string. Returns `true` on success. |
| `removeSelected()` | Removes all currently selected chips and returns focus to the input. |
| `getValues()` | Returns an array of all current chip values in order. |
| `getSelectedValues()` | Returns an array of selected chip values. |
| `clear()` | Removes all chips. |
| `clearSelection()` | Deselects all chips without removing them. |
| `selectChip(chip, options)` | Selects a chip element. Accepts `{ addToSelection, rangeSelect }` options. |
| `focus()` | Focuses the ghost input. |
| `dispose()` | Destroys the component and removes all event listeners. |
| `getInstance(element)` | Static — returns the instance bound to a container, or `null`. |
| `getOrCreateInstance(element)` | Static — returns the instance bound to a container, or creates one. |
</CxTable>

```js
const el = document.querySelector('.form-input.chip-input')
const chipInput = ChipInput.getOrCreateInstance(el)

chipInput.add('JavaScript')
chipInput.add('TypeScript')

console.log(chipInput.getValues()) // ['JavaScript', 'TypeScript']

chipInput.remove('JavaScript')
chipInput.clear()
```

### Options

<JsDataAttributes />

<CxTable>
| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `separator` | string \| null | `','` | Character that triggers chip creation when typed. Set to `null` to disable. |
| `allowDuplicates` | boolean | `false` | Allow duplicate chip values. |
| `maxChips` | number \| null | `null` | Maximum number of chips allowed. `null` for no limit. |
| `placeholder` | string | `''` | Placeholder of the `.ghost-input` that the plugin creates when the markup has none. |
| `dismissible` | boolean | `true` | Append a close button to each chip. |
| `dismissText` | string | `'×'` | Text of the close button. |
| `createOnBlur` | boolean | `true` | Create a chip from the current input value when focus leaves the field. |
| `chipClass` | string | `'default'` | Space-separated chip modifier classes applied to every created chip. Overridden by the `data-cx-chips` attribute value. |
</CxTable>

### Events

All events fire on the container. `add.cx.chip-input` and `remove.cx.chip-input` fire before the change and are cancelable.

<CxTable>
| Event | Description |
| --- | --- |
| `add.cx.chip-input` | Fired before a chip is added. The event carries a `value` property. Call `event.preventDefault()` to cancel. |
| `remove.cx.chip-input` | Fired before a chip is removed. The event carries `value` and `chip` properties. Call `event.preventDefault()` to cancel. |
| `change.cx.chip-input` | Fired after any chip is added or removed. The event carries a `values` array with all current chip values. |
| `select.cx.chip-input` | Fired when chip selection changes. The event carries a `selected` array of selected values. |
</CxTable>

```js
const el = document.querySelector('.form-input.chip-input')

el.addEventListener('add.cx.chip-input', event => {
  if (event.value.length < 2) {
    event.preventDefault() // reject values shorter than 2 characters
  }
})

el.addEventListener('change.cx.chip-input', event => {
  console.log('Current values:', event.values)
})
```
