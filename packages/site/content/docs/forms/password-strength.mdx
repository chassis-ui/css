## Introduction

A strength meter scores a password while the user types it and shows the result as one of four levels: weak, fair, good and strong. The plugin computes the score from the length of the password and the kinds of characters in it, and the CSS colors the meter by level.

### Key features

The component has two forms and a configurable score:

- **Segmented meter** — four segments that fill up to the current level
- **Progress bar** — a single bar that grows with the level
- **Text feedback** — an optional message for each level
- **Configurable scoring** — minimum length, the weight of each criterion, the thresholds of the levels, or a custom scoring function
- **Static display** — the same markup shows a fixed level without the plugin

## Basic structure

The default meter is a `.strength` element with four `.strength-segment` children, placed in the same parent as the password input. Add `data-cx-strength` to enable the plugin: the segments fill one by one as the strength of the password increases.

<Example code={`<div>
    <label for="password1" class="form-label">Password</label>
    <input type="password" autocomplete="new-password" class="form-input" id="password1" placeholder="Enter password">
    <div class="strength" data-cx-strength>
      <div class="strength-segment"></div>
      <div class="strength-segment"></div>
      <div class="strength-segment"></div>
      <div class="strength-segment"></div>
    </div>
  </div>`} />

## Text feedback

Add a `.strength-text` element next to the meter to display a message for the current level. The plugin writes the message and colors it with the context of the level.

<Example code={`<div>
    <label for="password2" class="form-label">Password</label>

## Progress bar

Use `.strength-bar` instead of `.strength` for a single bar that grows with the strength of the password. It needs no child elements.

<Example code={`<div>
    <label for="password3" class="form-label">Password</label>
    <input type="password" autocomplete="new-password" class="form-input" id="password3" placeholder="Enter password">
    <div class="strength-bar" data-cx-strength></div>
  </div>`} />

A meter shows a fixed level without the plugin when the markup carries the state itself, for content rendered on the server or for a legend of the levels. The plugin leaves a meter alone when its parent holds no password input.

## Strength criteria

The default scoring gives a password one point for each criterion it meets:

<CxTable>
| Criteria | Points |
| --- | --- |
| Meets minimum length (8 characters) | +1 |
| 4+ characters over minimum | +1 |
| Contains lowercase letters | +1 |
| Contains uppercase letters | +1 |
| Contains numbers | +1 |
| Contains special characters | +1 |
| Multiple special characters | +1 |
| 16+ characters | +1 |
</CxTable>

The score maps to a level through the `thresholds` option. An empty password has no level.

<CxTable>
| Level | Points |
| --- | --- |
| Weak | 1-2 |
| Fair | 3-4 |
| Good | 5-6 |
| Strong | 7-8 |
</CxTable>

## Accessibility

The meter conveys the strength through color and size only, and the plugin sets no ARIA attribute. Three practices make the feedback available to everyone:

- State the password requirements in text next to the input, and associate that text with the input through `aria-describedby`.
- Add the `.strength-text` element, so the level is also available as text.
- Add `aria-live="polite"` to the `.strength-text` element so screen readers announce the level when it changes.

## JavaScript API

The Strength plugin scores the password of an input, updates the meter and the text, and fires an event when the level changes. Chassis JS ships as an ES module — import the `Strength` class:

```js
import { Strength } from '@chassis-ui/css'
```

### Triggers

An element with `data-cx-strength` is initialized when the page loads. The plugin uses the first `input[type="password"]` in the parent of that element, unless `data-cx-input` names another one.

<CxTable>
| Attribute | Description |
| --- | --- |
| `data-cx-strength` | Initializes the strength indicator on the element (`.strength` or `.strength-bar`). |
| `data-cx-input` | CSS selector for the password field when it is not in the same parent as the meter. |
| `data-cx-min-length` | Minimum length used when computing the strength score. |
</CxTable>

```html
<div>
  <input type="password" autocomplete="new-password" class="form-input">
  <div class="strength" data-cx-strength>
    <div class="strength-segment"></div>
    <div class="strength-segment"></div>
    <div class="strength-segment"></div>
    <div class="strength-segment"></div>
  </div>
</div>
```

### Initialization

Create an instance with the `Strength` class to pass the options as an object, such as the messages or a scoring function:

```js
const element = document.querySelector('.strength')
const strength = new Strength(element, {
  input: '#my-password-input',
  minLength: 10,
  messages: {
    weak: 'Too weak',
    fair: 'Could be better',
    good: 'Good password',
    strong: 'Excellent!'
  }
})
```

### Methods

The plugin exposes instance methods to read the level and to score the password again:

<CxTable>
| Method | Description |
| --- | --- |
| `getStrength()` | Returns the current strength level (`'weak'`, `'fair'`, `'good'`, `'strong'`, or `null`). |
| `evaluate()` | Scores the current value of the input again, for example after a script has changed it. |
| `dispose()` | Destroys the component instance. |
| `getInstance(element)` | Static — returns the instance bound to an element, or `null`. |
| `getOrCreateInstance(element)` | Static — returns the instance bound to an element, or creates one. |
</CxTable>

```js
const element = document.querySelector('.strength')
const strength = Strength.getOrCreateInstance(element)

// Get current strength
console.log(strength.getStrength()) // 'fair'
```

### Options

<JsDataAttributes />

<CxTable>
| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `input` | string \| element | `null` | Selector or element for the password input. If not provided, the plugin uses the first `input[type="password"]` in the parent of the meter. |
| `minLength` | number | `8` | Minimum password length for first strength point. |
| `messages` | object | `{weak, fair, good, strong}` | Custom messages for each strength level. |
| `weights` | object | `1` for each criterion | Point values for each scoring criterion. Set one to `0` to disable the criterion. |
| `thresholds` | array | `[2, 4, 6]` | Score boundaries for strength levels: `[weak, fair, good]`. Scores above the last value are "strong". |
| `scorer` | function | `null` | Custom scoring function `(password) => number`. Overrides built-in scoring when provided. |
</CxTable>

The `weights` object has one key for each criterion of the default scoring:

```js
{
  minLength: 1,        // Meets minimum length
  extraLength: 1,      // 4+ characters over minimum
  lowercase: 1,        // Contains lowercase letters
  uppercase: 1,        // Contains uppercase letters
  numbers: 1,          // Contains numbers
  special: 1,          // Contains special characters
  multipleSpecial: 1,  // Multiple special characters
  longPassword: 1      // 16+ characters
}
```

Changed weights change the highest possible score, so adjust `thresholds` with them:

```js
// Disable uppercase requirement, make special chars worth more
new Strength(element, {
  weights: {
    uppercase: 0,   // Don't require uppercase
    special: 2      // Special chars worth 2 points
  },
  thresholds: [3, 5, 7]  // Adjust thresholds for new max score
})
```

A `scorer` function replaces the default scoring altogether; the thresholds still map its result to a level:

```js
// Fully custom scoring logic
new Strength(element, {
  scorer: (password) => {
    let score = 0
    if (password.length >= 12) score += 4
    if (/[!@#$%]/.test(password)) score += 4
    return score
  },
  thresholds: [2, 4, 6]
})
```

### Events

The event fires on the element with `data-cx-strength`, and only when the level changes, not on every keystroke.

<CxTable>
| Event | Description |
| --- | --- |
| `strengthChange.cx.strength` | Fired when the strength level changes. Includes the `strength` and `score` properties; the password itself is not part of the event. |
</CxTable>

```js
const element = document.querySelector('.strength')

element.addEventListener('strengthChange.cx.strength', event => {
  console.log('Strength:', event.strength) // 'weak', 'fair', 'good', 'strong' or null
  console.log('Score:', event.score) // 0-8
})
```
