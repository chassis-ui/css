## Introduction

A range input is a slider for choosing a numeric value between two bounds. The `.form-range` class styles the native `<input type="range">` element: it draws the same track and thumb in every browser and adds the focus ring of the form controls.

## Basic structure

Add `.form-range` to an `<input type="range">` and connect it to a `<label>`.

<Example code={`<label for="rangeExample" class="form-label">Basic range slider</label>
<input type="range" class="form-range" id="rangeExample">`} />

### Disabled state

Add the `disabled` attribute to a range input to make it unavailable. The thumb takes its disabled color, pointer events are removed, and the browser skips the input in the tab order.

<Example code={`<label for="disabledRange" class="form-label">Disabled range slider</label>
<input type="range" class="form-range" id="disabledRange" disabled>`} />

## Range configuration

The native `min`, `max`, and `step` attributes set the bounds of the slider and the increment between its values.

### Min and max values

A range input runs from 0 to 100 by default. Set `min` and `max` for another scale.

<Example code={`<label for="customRange" class="form-label">Custom range (0-5)</label>
<input type="range" class="form-range" min="0" max="5" id="customRange">`} />

### Step increments

A range input moves in steps of 1 by default. Set `step` to a decimal value for finer increments.

<Example code={`<label for="preciseRange" class="form-label">Range with 0.5 step increments</label>
<input type="range" class="form-range" min="0" max="5" step="0.5" id="preciseRange">`} />

## Contextual usage

Range inputs combine with other elements of a form: an output that shows the current value, and grid columns that place the slider next to other controls.

### With value display

A slider does not show its value. Pair it with an `<output>` element that a script updates on the `input` event.

<Example code={`<div class="d-flex">
    <label for="rangeWithOutput" class="form-label">Temperature (°C)</label>
    <output for="rangeWithOutput" id="rangeOutput" class="ms-auto">22</output>
  </div>
  <input type="range" class="form-range" min="15" max="30" value="22" id="rangeWithOutput"
    oninput="rangeOutput.value = this.value">`} />

### Form layouts

Use the [grid system]([[docsref:/layout/grid]]) and the layout utilities to arrange range inputs alongside other form controls.

<Example code={`<div class="grid gap-md">
  <div class="col-span-full md:col-span-6">
    <label for="volumeRange" class="form-label">Volume</label>
    <input type="range" class="form-range" min="0" max="100" value="75" id="volumeRange">
  </div>
  <div class="col-span-full md:col-span-6">
    <label for="brightnessRange" class="form-label">Brightness</label>
    <input type="range" class="form-range" min="0" max="100" value="50" id="brightnessRange">
  </div>
</div>`} />

## Accessibility

A range input is a native control with the `slider` role, so the markup only has to supply its name and, where needed, a readable value:

- Always associate a visible `<label>` with the input using the `for` attribute so the control has an accessible name.
- Use `aria-valuetext` when the numeric value alone doesn't convey meaning to the user — for example, a satisfaction scale where `1` should be announced as "Very dissatisfied" rather than "1".
- Use `aria-describedby` to associate a `.form-help` element with the input when additional context is needed, so screen readers announce the description when the field receives focus.
- Pair range inputs with a visible value display (such as an `<output>` element) so sighted users can see the exact value while adjusting the slider.
- Range inputs are keyboard-navigable by default: arrow keys adjust by one step, and `Home`/`End` jump to the minimum and maximum values.
