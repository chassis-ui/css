## Introduction

An OTP (one-time password) input groups single-character fields into one control for verification codes, PINs, and two-factor authentication.

The component builds on [form inputs]([[docsref:/forms/form-input]]). Its plugin moves the focus to the next field after each digit and back to the previous one on <kbd>Backspace</kbd>, distributes a pasted code across the fields, and moves between fields with the arrow keys. The first field receives `autocomplete="one-time-code"`, which lets browsers that support it fill in a code from an SMS or an email.

## Basic structure

Wrap the inputs in a container with `.form-otp` and add `data-cx-otp` to enable the plugin. Give each input the `.form-input` class; the plugin limits every field to a single digit.

<Example code={`<div class="form-otp" data-cx-otp role="group" aria-label="Verification code">
    <input type="text" class="form-input" aria-label="Digit 1">
    <input type="text" class="form-input" aria-label="Digit 2">
    <input type="text" class="form-input" aria-label="Digit 3">
    <input type="text" class="form-input" aria-label="Digit 4">
    <input type="text" class="form-input" aria-label="Digit 5">
    <input type="text" class="form-input" aria-label="Digit 6">
  </div>`} />

## Four-digit PIN

The plugin works with the inputs it finds in the container, whatever their number. Use fewer inputs for shorter codes such as a four-digit PIN.

<Example code={`<div class="form-otp input-group" data-cx-otp role="group" aria-label="Verification code">

<Example code={`<div class="form-otp" data-cx-otp role="group" aria-label="Verification code">

    <input type="text" class="form-input" aria-label="Digit 2">
    <input type="text" class="form-input" aria-label="Digit 3">

## Accessibility

The fields of an OTP input have no visible labels of their own, so the markup has to name each field and the group. The plugin sets no ARIA attribute.

### Individual input labels

Each digit input needs an `aria-label` describing its position — for example `aria-label="Digit 1"`. Without it, screen readers have no way to distinguish between the fields.

### Container labeling

Label the OTP group as a whole with a visible `<label>` linked through `aria-labelledby` on the container, so screen readers announce the purpose of the group before the individual inputs:

```html
<label class="form-label" id="otpLabel">Verification code</label>
<div class="form-otp" data-cx-otp role="group" aria-labelledby="otpLabel">
  ...
</div>
```

When no visible label is appropriate, use `aria-label` on the container instead. Both attributes need `role="group"` on the container to take effect.

### Help text

Associate instructional text with the group through `aria-describedby` on the container:

```html
<div class="form-otp" data-cx-otp role="group" aria-describedby="otpHelp">
  ...
</div>
<div id="otpHelp" class="form-help">Enter the 6-digit code sent to your phone.</div>
```

### Keyboard and mobile

The plugin sets `inputmode="numeric"` and `pattern="\d*"` on each input, which brings up the numeric keyboard on mobile devices without changing the input type, and it removes any character that is not a digit.

<CxTable>
| Key | Action |
| --- | --- |
| A digit | Fill the field and move to the next one. |
| <kbd>←</kbd> / <kbd>→</kbd> | Move to the previous or next field. |
| <kbd>Backspace</kbd> | In an empty field, clear the previous field and move to it. |
| <kbd>Delete</kbd> | Clear the field and shift the digits after it one field back. |
</CxTable>

## JavaScript API

The OtpInput plugin handles the focus, the paste and the keys of the fields, and fires an event when the code is complete. Chassis JS ships as an ES module — import the `OtpInput` class:

```js
import { OtpInput } from '@chassis-ui/css'
```

### Triggers

A container with `data-cx-otp` is initialized when the page loads.

<CxTable>
| Attribute | Description |
| --- | --- |
| `data-cx-otp` | Initializes the OTP input on the container wrapping the digit fields. |
| `data-cx-mask` | When `true`, uses password fields to mask entered digits. |
</CxTable>

```html
<div class="form-otp" data-cx-otp role="group" aria-label="Verification code">
  <input type="text" class="form-input" aria-label="Digit 1">
  <input type="text" class="form-input" aria-label="Digit 2">
  <input type="text" class="form-input" aria-label="Digit 3">
  <input type="text" class="form-input" aria-label="Digit 4">
</div>
```

### Initialization

Create an instance with the `OtpInput` class for a container added after the page has loaded, or to call its methods:

```js
const otpElement = document.querySelector('.form-otp')
const otpInput = new OtpInput(otpElement)
```

### Methods

The plugin exposes instance methods to read, set and clear the code:

<CxTable>
| Method | Description |
| --- | --- |
| `getValue()` | Returns the complete OTP value as a string. |
| `setValue(value)` | Sets the OTP value, distributing characters across inputs. |
| `clear()` | Clears all inputs and focuses the first one. |
| `focus()` | Focuses the first empty input, or the last input if all are filled. |
| `dispose()` | Destroys the component instance. |
| `getInstance(element)` | Static — returns the instance bound to a container, or `null`. |
| `getOrCreateInstance(element)` | Static — returns the instance bound to a container, or creates one. |
</CxTable>

```js
const otpElement = document.querySelector('.form-otp')
const otpInput = OtpInput.getOrCreateInstance(otpElement)

// Get the current value
console.log(otpInput.getValue()) // "123456"

// Set a value programmatically
otpInput.setValue('654321')

// Clear all inputs
otpInput.clear()
```

### Options

<JsDataAttributes />

<CxTable>
| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `mask` | boolean | `false` | If `true`, the inputs use `type="password"` to hide the entered values. |
</CxTable>

### Events

Both events fire on the container.

<CxTable>
| Event | Description |
| --- | --- |
| `complete.cx.otp-input` | Fired when all inputs are filled: after typing, a paste, or `setValue()`. The event's `value` property contains the complete code. |
| `input.cx.otp-input` | Fired on each input change made in the fields: typing, <kbd>Backspace</kbd>, <kbd>Delete</kbd> and paste. Includes `value` (current combined value) and `index` (changed input index). Not fired by `setValue()` or `clear()`. |
</CxTable>

```js
const otpElement = document.querySelector('.form-otp')

otpElement.addEventListener('complete.cx.otp-input', event => {
  console.log('OTP complete:', event.value)
  // Submit the form or validate the code
})

otpElement.addEventListener('input.cx.otp-input', event => {
  console.log('Current value:', event.value, 'Changed index:', event.index)
})
```
