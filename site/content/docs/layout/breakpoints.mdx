import { sassBreakpointSize } from '@libs/sass'

Breakpoints are the minimum widths at which the layout system, responsive utilities, and component variants shift behavior. The framework ships six default breakpoints as a Sass map (`$breakpoints`); all values are overridable before importing Chassis. [The Tailwind entry point]([[docsref:/getting-started/tailwind]]) reads this same map to drive its `sm:`–`2xl:` and `@md:`–`@2xl:` variant prefixes, in place of Tailwind's own default scale.

## Available breakpoints

The six default breakpoints feed the grid system, responsive utilities, and all breakpoint mixins. Override `$breakpoints` to change all responsive thresholds at once — see [Sass variables](#sass-variables) for the source declaration.

<CxTable>
| Breakpoint | Class prefix | Dimensions |
| --- | --- | --- |
| XS | <em>None</em> | &lt;{sassBreakpointSize('sm')} |
| SM | `sm` | &ge;{sassBreakpointSize('sm')} |
| MD | `md` | &ge;{sassBreakpointSize('md')} |
| LG | `lg` | &ge;{sassBreakpointSize('lg')} |
| XL | `xl` | &ge;{sassBreakpointSize('xl')} |
| 2XL | `2xl` | &ge;{sassBreakpointSize('2xl')} |
</CxTable>

<Callout type="info">
`2xl` starts with a digit. Chassis CSS CSS-escapes the leading digit automatically when generating class names (e.g. `\32 xl\:`), producing a valid CSS identifier. The naming follows the same scale used across sizing tokens and utility classes throughout the framework.
</Callout>

## Media queries

All queries use [CSS range syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_media_queries/Using_media_queries#syntax_improvements_in_level_4), driven by the values in `$breakpoints`. The system is mobile-first: `xs` has a value of `0`, so styles defined at that level apply at all widths and no wrapping query is emitted.

### Min-width

`media-breakpoint-up()` applies styles from a given breakpoint and wider. Calling it with `xs` emits no wrapping query, since `xs` has a value of `0`.

```scss
// No media query for `xs` — it targets all viewport widths (value 0)
@include media-breakpoint-up(sm) { ... }
@include media-breakpoint-up(md) { ... }
@include media-breakpoint-up(lg) { ... }
@include media-breakpoint-up(xl) { ... }
@include media-breakpoint-up(2xl) { ... }

// Hide at the smallest size, then reveal at `sm` and wider
.custom-class {
  display: none;
}
@include media-breakpoint-up(sm) {
  .custom-class {
    display: block;
  }
}
```

These mixins compile to range queries using the values in `$breakpoints`:

<Code lang="scss" code={`// No media query for \`xs\` — the default in Chassis

// Small devices (landscape phones, ${sassBreakpointSize('sm')} and up)
@media (width >= ${sassBreakpointSize('sm')}) { ... }

// Medium devices (tablets, ${sassBreakpointSize('md')} and up)
@media (width >= ${sassBreakpointSize('md')}) { ... }

// Large devices (desktops, ${sassBreakpointSize('lg')} and up)
@media (width >= ${sassBreakpointSize('lg')}) { ... }

// X-Large devices (large desktops, ${sassBreakpointSize('xl')} and up)
@media (width >= ${sassBreakpointSize('xl')}) { ... }

// 2X-Large devices (larger desktops, ${sassBreakpointSize('2xl')} and up)
@media (width >= ${sassBreakpointSize('2xl')}) { ... }`} />

### Max-width

`media-breakpoint-down()` applies styles at a given breakpoint and narrower. Calling it with `xs` emits no wrapping query, since `breakpoint-max(xs)` returns `null` when the breakpoint's value is `0`.

```scss
// No media query for `xs` since its breakpoint value is 0
@include media-breakpoint-down(sm) { ... }
@include media-breakpoint-down(md) { ... }
@include media-breakpoint-down(lg) { ... }
@include media-breakpoint-down(xl) { ... }
@include media-breakpoint-down(2xl) { ... }

// Style from md and narrower
@include media-breakpoint-down(md) {
  .custom-class {
    display: block;
  }
}
```

These mixins compile to `width <` range queries using the raw breakpoint value as the exclusive upper bound:

<Code lang="scss" code={`// \`xs\` emits only a ruleset — no wrapping media query

// \`sm\` — narrower than ${sassBreakpointSize('sm')}
@media (width < ${sassBreakpointSize('sm')}) { ... }

// \`md\` — narrower than ${sassBreakpointSize('md')}
@media (width < ${sassBreakpointSize('md')}) { ... }

// \`lg\` — narrower than ${sassBreakpointSize('lg')}
@media (width < ${sassBreakpointSize('lg')}) { ... }

// \`xl\` — narrower than ${sassBreakpointSize('xl')}
@media (width < ${sassBreakpointSize('xl')}) { ... }

// \`2xl\` — narrower than ${sassBreakpointSize('2xl')}
@media (width < ${sassBreakpointSize('2xl')}) { ... }`} />

### Single breakpoint

`media-breakpoint-only()` applies styles within a single breakpoint range — from its own minimum width up to, but not including, the next breakpoint's minimum. For `xs`, there is no lower bound, so the mixin falls back to `media-breakpoint-down(sm)`. For `2xl`, there is no upper bound, so the mixin falls back to `media-breakpoint-up(2xl)`.

```scss
@include media-breakpoint-only(xs) { ... }
@include media-breakpoint-only(sm) { ... }
@include media-breakpoint-only(md) { ... }
@include media-breakpoint-only(lg) { ... }
@include media-breakpoint-only(xl) { ... }
@include media-breakpoint-only(2xl) { ... }
```

For example, `@include media-breakpoint-only(md) { ... }` compiles to:

<Code lang="scss" code={`@media (width >= ${sassBreakpointSize('md')}) and (width < ${sassBreakpointSize('lg')}) { ... }`} />

### Between breakpoints

`media-breakpoint-between()` applies styles across a span of breakpoints — from the first argument's minimum up to, but not including, the second argument's minimum. When the lower bound is `xs` (value `0`), the mixin falls back to `media-breakpoint-down()` on the upper bound.

```scss
@include media-breakpoint-between(md, xl) { ... }
```

This compiles to:

<Code lang="scss" code={`@media (width >= ${sassBreakpointSize('md')}) and (width < ${sassBreakpointSize('xl')}) { ... }`} />

## Container queries

Container query mixins mirror the [media query mixins](#media-queries) and respond to the inline size of a containing element rather than the viewport. Every mixin accepts an optional `$container-name` argument to scope the query to a named container.

### Setting a container

`set-container()` establishes an element as a query container. The `$type` argument sets the `container-type` property; the optional `$name` argument produces the `container` shorthand.

```scss
@include set-container()                      // => container-type: inline-size
@include set-container(size)                  // => container-type: size
@include set-container(inline-size, sidebar)  // => container: sidebar / inline-size
```

### Container min-width

`container-breakpoint-up()` applies styles when the container is at least as wide as the given breakpoint. No query is emitted for `xs`.

<Code lang="scss" code={`@include container-breakpoint-up(md) { ... }
// => @container (width >= ${sassBreakpointSize('md')}) { ... }`} />

### Container max-width

`container-breakpoint-down()` applies styles when the container is narrower than the given breakpoint. No query is emitted for `xs` (value `0`).

<Code lang="scss" code={`@include container-breakpoint-down(md) { ... }
// => @container (width < ${sassBreakpointSize('md')}) { ... }`} />

### Container range

`container-breakpoint-only()` and `container-breakpoint-between()` work identically to their media query counterparts, scoped to the container.

<Code lang="scss" code={`@include container-breakpoint-only(md) { ... }
// => @container (width >= ${sassBreakpointSize('md')}) and (width < ${sassBreakpointSize('lg')}) { ... }

@include container-breakpoint-between(sm, lg) { ... }
// => @container (width >= ${sassBreakpointSize('sm')}) and (width < ${sassBreakpointSize('lg')}) { ... }`} />

### Named containers

Without a name, a container query always targets the nearest ancestor container. In a nested layout — where a `sidebar` sits inside an outer `main` region — a widget inside the sidebar can only respond to the sidebar by default, never to the outer main. Named containers solve this by letting a descendant target any specific ancestor, regardless of nesting depth.

<Code lang="scss" code={`// Outer layout region — named "main"
  .main {
    @include set-container(inline-size, main);
    // => container: main / inline-size
  }

  // Sidebar nested inside the main — named "sidebar"
  .sidebar {
    @include set-container(inline-size, sidebar);
    // => container: sidebar / inline-size
  }

  // Widget is a descendant of both containers.
  // The name passed to each mixin determines which container drives that query.
  .sidebar-widget {
    @include container-breakpoint-up(lg, main) { ... }
    // => @container main (width >= 992px) { ... }

    @include container-breakpoint-down(sm, sidebar) { ... }
    // => @container sidebar (width < 576px) { ... }
  }`} />

The first rule fires when `main` reaches `lg`; the second fires when `sidebar` drops below `sm`. The same descendant responds to two independent containers simultaneously.
